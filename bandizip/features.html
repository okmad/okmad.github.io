压缩功能：快、强、稳

Bandizip 采用多核并行压缩技术，能够同时调用 CPU 的多个核心处理数据，相比传统单核压缩软件，压缩速度最高可提升6倍。无论是对付几个 G 的游戏资源包，还是日常办公文档打包，都能明显感觉到速度优势。

支持压缩的格式

ZIP 7Z (LZMA2) ZIPX (XZ) EXE (自解压) TAR TGZ LZH (LH7) ISO (Joliet) GZ XZ

实用压缩特性

  • 分卷压缩：可将大文件分割成多个指定大小的压缩包，方便邮件发送或分批传输，完全遵循国际标准 ZIP 分卷规范。
  • 大文件支持：支持 4GB 以上超大文件的压缩，处理高清视频、游戏镜像毫无压力。
  • 密码保护：压缩时可为文件设置密码，采用 AES-256 加密算法，安全性媲美银行级标准。
  • 文件名加密：开启后压缩包内的文件名也会被加密隐藏，他人即使打开压缩包也看不到内容列表。

解压功能：一键解锁所有压缩包

Bandizip 拥有业内领先的格式兼容性，可解压40多种压缩格式，几乎覆盖了您能在网上遇到的所有压缩包类型。遇到陌生格式的压缩文件，交给 Bandizip 就对了。

支持解压的格式（部分）

7Z ACE AES ALZ ARJ BH BIN BR BZ2 CAB DEB EGG IMG ISO ISZ LHA LZ4 LZH LZMA PMA RAR RAR5 TAR TBZ2 TGZ TLZ TXZ UDF WIM XPI XZ Z ZIP ZIPX ZPAQ ZSTD NSIS

智能解压体验

  • 智能自动解压：压缩包里是散文件时自动创建同名文件夹收纳；只有一个文件夹时直接解压不套娃，桌面永远整洁。
  • 一步解压 TGZ/TBZ：Linux 常见的双重压缩包（.tar.gz）可一步到位直接解压，无需解压两次。
  • 拖放解压：打开压缩包后，直接拖动文件到资源管理器即可解压指定文件。
  • 代码页自动识别：智能识别压缩包内文件的编码，日文、韩文等外文文件名不再乱码。
  • 文件列表预览：双击压缩包即可查看内部文件列表，无需先解压。

安全与可靠性

Bandizip 不只是追求速度，安全性同样出色，多个功能为您的文件安全保驾护航。

安全功能清单

  • 完整性检查：解压后自动校验文件是否损坏，确保下载的压缩包完整可用。
  • 恶意代码检测：解压前可调用 Windows 反恶意软件接口扫描压缩包，杜绝压缩包内藏毒。
  • 修复压缩包（专业版）：分析损坏的 ZIP 压缩包结构，尽可能恢复其中的文件数据。
  • 密码恢复（专业版）：忘记压缩包密码时，可通过暴力破解方式尝试找回密码。

专业版专属功能

Bandizip 免费版已能满足日常压缩解压需求，专业版则面向重度用户提供了更多生产力功能：

  • 密码管理器：集中管理各类压缩包密码，压缩/解压时自动填充，告别手动输入。
  • 压缩包图片预览：无需解压，直接查看压缩包内图片的缩略图，找素材快人一步。
  • 无广告体验：专业版不含任何广告，界面清爽纯粹。
  • 商业使用授权：企业用户购买专业版授权后可合法商业部署。

跨平台支持

Bandizip 同时提供 Windows 与 macOS 双平台原生版本：

  • Windows 版：支持 Windows 7 / 8 / 8.1 / 10 / 11，覆盖 32位（x86）、64位（x64）与 ARM64 架构，另提供免安装便携版。
  • macOS 版：同时支持 Intel 与 Apple Silicon（M系列）芯片，完美适配新款 Mac。
  • 多国语言：内置简体中文、繁体中文、英文、日文、韩文等20多种界面语言。
