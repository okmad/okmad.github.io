Obsidian 更新日志

记录每个版本的新功能、改进与问题修复，了解 Obsidian 的持续进化

1.12.7 桌面端 Desktop
2026-03-23

改进 改进

  • Obsidian CLI：安装程序现在捆绑了新的 CLI 二进制文件，取代旧的调用 Electron 二进制文件方式，终端交互速度显著提升。
  • Obsidian CLI：在使用 id= 参数时，为终端界面（TUI）添加了 Obsidian 命令的自动补全。

问题修复 修复

  • Obsidian CLI：修复了在 macOS 上错误检查 Linux 特定目录的问题。
  • Obsidian CLI：在 macOS 和 Linux 上将 CLI 套接字文件更改为隐藏的点文件。
  • 编辑器：修复了未选中文本时复制、剪切和粘贴的若干问题。复制粘贴一行不再将光标置于错误位置；表格中无选择复制或剪切现在只复制单元格内容。
  • 编辑器：在多光标选中文本时粘贴 URL，现在会将每个选区包装为 Markdown 链接 [选中文本](url)。
  • 编辑器：修复了阅读模式下 Callout 内图片显示多余滚动条的问题。
  • 编辑器：修复了实时预览中双击图片不重置大小的问题。

开发者

  • 安装程序已更新至 Electron v39.8.3。

1.12.4 桌面端 Desktop
2026-02-27

新功能 新功能

  • Obsidian CLI：本次发布引入了 Obsidian CLI 命令行界面，可从终端控制 Obsidian，用于脚本编写、自动化及与外部工具集成。
  • 图片缩放：实时预览中的图片现在可以通过拖动角落调整大小，双击角落可重置图片尺寸。
  • 自动清理附件：删除文件时会询问是否同时删除其附件。"文件与链接"设置中可配置该行为（选择"总是""每次询问"或"从不"）。

改进 改进

  • Bases：添加了搜索工具栏按钮以筛选查询结果；支持通过拖放将文件导入 Bases；表格视图中右键单击单行现在显示与该文件相关的上下文菜单。
  • 文件浏览器：现在支持使用 Ctrl-C/Ctrl-V（macOS 为 Cmd-C/Cmd-V）进行复制粘贴操作。
  • 编辑器：右键单击编辑器旁空白处新增菜单项——切换行号、切换内联标题。
  • 编辑器：修复了引用块后缺少空格的问题；修复了粗体链接的样式问题。
  • Canvas 文件现在支持反向链接检测，会显示在反向链接视图中，并计入图谱视图的链接。
  • "切换库..."已重命名为"管理库"；新增"切换库..."和"打开库..."命令，支持键盘快速切换。
  • 快速切换器支持拖拽结果；右键图片新增"复制图片"菜单项。
  • 从编辑器复制文本现在包含 HTML 格式，便于粘贴到 Google Docs 等应用。
  • Obsidian Sync 现在会记录因文件过大被跳过的日志。
  • 改进了查询包含空格时的模糊搜索结果。
  • 在外部应用打开文件现在显示确认对话框；打开可执行文件时新增警告。

问题修复 修复

  • 密钥链：为部分 Linux 机器上加密不可用的情况添加了处理。
  • 修复了应用关闭时布局未始终保存的问题。
  • 修复了在链接或标签附近选中文本会错误触发链接或标签的问题。
  • 修复了关闭弹出窗口时活动通知会移动到主窗口且永不消失的问题。
  • 修复了输入时大纲视图闪烁的问题；修复了 Bases 表格视图行高更改后滚动位置不更新的问题。
  • 文件浏览器：修复了复制包含"."的文件夹时生成不完整文件夹名的问题。

开发者

  • 安装程序已更新至 Electron v39.7.0。
  • 更新了翻译文件的创建与打包方式。
  • 新增 corner-shape CSS 属性的主题支持，替换 -electron-corner-smoothing（需 Chromium 139 和 Obsidian 1.11+）。
  • macOS：新增 traffic-lights-offset-x 和 --traffic-lights-offset-y CSS 变量配置窗口红绿灯位置。
  • vault 和 adapter API 新增 appendBinary 方法。
1.12.4 移动端 Mobile
2026-02-27

新功能 新功能

  • iOS：新增分享扩展，可从其他应用（如 Safari、社交网络）保存内容到库，无需打开 Obsidian。
  • iOS：新增"书签链接"快捷操作，可将 URL 保存为 Obsidian 书签。

改进 改进

  • 应用现在默认使用系统语言，并在引导过程中提供语言选择器。
  • 新增"唯一笔记"应用操作（长按应用图标时显示的菜单）。
  • 改进了平板上指针设备（如 Magic Trackpad）的支持：子菜单悬停展开，属性编辑器右键显示上下文菜单。

问题修复 修复

  • 移除了文件删除提示中的"删除且不再询问"选项。
  • Obsidian Sync：修复了应用在 Obsidian 保存最新同步状态前关闭时文件被覆盖的问题。
  • iOS：修复了工具提示有时在与侧边栏项目交互后出现的问题；修复了每日笔记和书签快捷方式不工作的问题；修复了查看笔记小组件不立即刷新的问题。
  • Slides：修复了移动端状态栏中关闭按钮的位置。

问题修复 修复

1.12.2 桌面端 Desktop
2026-02-18

改进 改进

  • CLI：新增 help 命令及 --help 别名；新增 daily:path 命令获取每日笔记路径；新增 rename 重命名命令；将 search 命令拆分为 search 和 search:context。
  • CLI：命令现在默认静默运行，不再默认期望活动文件。all 参数被 active 替换，silent 参数被 open 替换。CLI 现在忽略以 -- 开头的无法识别的标志。
  • Bases：支持通过拖放将文件导入 Bases；file.linksTo() 将 Canvas 中嵌入的文件视为链接。
  • 右键图片新增"复制图片"菜单项；从编辑器复制文本现在包含 HTML 格式。
  • Obsidian Sync 现在会记录因文件过大被跳过的日志。
  • 改进了查询包含空格时的模糊搜索结果；在外部应用打开文件显示确认对话框；打开可执行文件新增警告。

问题修复 修复

  • 修复了通知被关闭后停止显示的问题；修复了输入时大纲视图闪烁的问题。
  • 修复了 Bases 表格视图行高更改后滚动位置不更新的问题；修复了搜索输入文本与结果计数重叠的问题。
  • 修复了点击弹出窗口"..."按钮时"更多选项"菜单不关闭的问题；修复了应用重启有时导致退出状态损坏的问题。
  • 修复了未启用 CLI 时 obsidian:// URI 不工作的问题。
  • CLI：修复了 Unicode 字符、粘贴、命令在工作区加载完成前运行、指定库未找到时错误操作当前库、Windows 上含冒号参数处理等多个问题。
  • macOS：CLI 调用期间不再显示 Dock 图标。

问题修复 修复
