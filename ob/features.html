编辑与书写

原生 Markdown 支持，三种编辑模式自由切换，满足不同书写习惯

📝 三种编辑模式

支持实时预览（所见即所得）、源码模式（纯 Markdown 语法）、阅读视图（纯阅读排版）三种模式自由切换，满足从写作到阅读的各种场景需求。

📋 块级引用

使用 ^块ID 语法可以为任意段落、列表项创建唯一标识，通过 ![[笔记#^块ID]] 精确引用甚至嵌入该块内容，实现段落级别的知识关联。

🏷️ 标签系统

支持 #标签 和 [[标签]] 两种形式，可嵌套层级标签（如 #项目/工作）。配合标签面板快速筛选与浏览，多维度组织笔记内容。

🔍 强大的搜索

全文搜索支持正则表达式、路径过滤、标签过滤等高级查询语法。配合搜索插件可按文件名、内容、标签等多维度快速定位笔记。

📊 嵌入内容

支持嵌入图片、音频、视频、PDF 等多种格式文件。通过 ![[笔记名]] 语法嵌入其他笔记内容，实现内容的复用与组合，自动同步更新。

⚡ 模板系统

内置模板功能，配合日期变量、光标定位等语法，一键生成标准化笔记结构。适合日记、会议纪要、读书笔记等重复性内容创作。

知识管理

构建互联的知识网络，让分散的笔记产生联系与价值

🔗

双向链接

使用 [[笔记名]] 语法即可创建笔记间的双向链接。Obsidian 自动追踪引用关系，在反向链接面板中展示所有引用当前笔记的其他笔记，让知识真正互联。

🕸️

关系图谱

将整个知识库可视化为节点网络图，直观展示笔记间的关联。支持按标签、文件夹、链接数等筛选与着色，发现孤立笔记，洞察知识结构。

🔄

反向链接

每条笔记都展示哪些笔记引用了它，方便追溯知识的来源与脉络。配合未链接提及功能，自动发现潜在的关联笔记，促进知识连接。

🗂️

多库管理

支持创建多个独立的库（Vault），将工作、学习、生活笔记分离管理。每个库拥有独立的配置、插件与主题设置，互不干扰。

📅

日记与日历

内置日记功能，配合日历插件直观浏览每日笔记。点击日期快速创建当日日记，支持自定义日记模板与命名格式，建立持续记录的习惯。

🧭

大纲与书签

大纲面板展示当前笔记的标题层级结构，快速跳转。书签功能收藏常用笔记、搜索结果、图谱视图，打造个人快捷导航中心。

扩展生态

开放的插件架构，上千款社区插件，无限可能

🧩 社区插件市场

Obsidian 拥有活跃的社区插件生态，上千款插件覆盖看板、日历、思维导图、数据库、Excalidraw 绘图、PDF 标注、Git 版本控制等各种需求，几乎能找到满足任何工作流的插件。

🎨 主题市场

丰富的主题市场提供上百款精美主题，从极简到炫酷风格应有尽有。支持深度自定义 CSS 外观，调整字体、颜色、间距等每一个细节，打造专属编辑环境。

🔧 核心插件

内置日记、模板、大纲、书签、关系图谱、反向链接、标签面板、命令面板等核心插件，可按需启用关闭。这些官方插件覆盖了最常见的使用场景。

💻 开发者 API

提供完整的 TypeScript 插件开发 API 与文档，开发者可以编写自定义插件扩展功能。开放的架构让 Obsidian 成为可无限扩展的知识管理平台。

🔄 版本控制集成

基于纯文本文件存储的特性，天然适配 Git 版本控制。配合 obsidian-git 插件，实现笔记的自动提交、同步与历史版本管理，永不丢失任何修改。

🌐 Web Clipper

官方浏览器扩展（Chrome、Firefox、Safari、Edge），一键剪藏网页内容为 Markdown 笔记，支持自定义模板与高亮筛选，便捷收集网络资料。

数据与安全

本地优先，隐私至上，数据完全掌控在自己手中

💾

纯文本本地存储

所有笔记以标准 Markdown 文件存储在本地硬盘，不锁定在云端。可用任意文本编辑器打开，无供应商锁定风险，数据永久可读可用。

🔒

端到端加密同步

官方 Sync 服务采用端到端加密，密钥仅你拥有，服务器无法解密你的笔记内容。跨设备同步的同时确保数据绝对私密安全。

🛡️

隐私保护

Obsidian 不会读取或上传你的笔记内容，所有处理在本地完成。无遥测、无广告、无数据收集，你的知识库完全属于你自己。

🌐

多平台同步

原生支持 Windows、macOS、Linux、iOS、Android。除官方 Sync 外，也可通过 iCloud、Google Drive、Git、Syncthing 等第三方方案实现同步。
