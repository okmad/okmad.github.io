文件操作快捷键

功能 快捷键 说明
新建文件 Ctrl + N 创建新的空白文件

保存文件 Ctrl + S 保存当前文件

快捷键使用技巧

  • 多行编辑：按住 Alt 键点击鼠标，可以在多个位置同时输入内容，非常适合批量修改
  • 列块选择：按住 Alt 键拖动鼠标，可以选择矩形区域，适合编辑表格数据
  • 快速复制行：Ctrl + D 可以快速复制当前行，比 Ctrl+C、Ctrl+V 更快
  • 宏录制：对于重复性操作，可以录制宏，然后一键执行
  • 代码折叠：使用 Alt + 0 折叠所有代码，方便查看文件结构
