Notepad++ 是什么？

Notepad++ 是 Windows 平台非常经典的一款文本编辑器， 拥有代码高亮、多标签编辑、插件扩展、正则查找替换等功能。

相比系统自带记事本，Notepad++ 功能更加强大， 非常适合程序开发、网站编辑、日志查看与配置文件修改。

为什么很多程序员喜欢 Notepad++？

因为它启动速度快，占用内存低，使用简单， 即使在低配置电脑上也能流畅运行。

很多开发者会使用 Notepad++ 编辑 HTML、PHP、JS、Python、 JSON、XML 等文件。
