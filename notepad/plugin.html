Notepad++ 插件推荐

🔍

Compare Plugin

强大的文件差异对比插件，支持双文件对比、差异高亮显示、行号对比等功能。非常适合代码审查、配置文件对比等场景。

必装插件

JSON Viewer

JSON格式化与树状解析工具，支持JSON语法高亮、格式化压缩、树状结构展示、错误检查等功能。前端开发必备。

推荐
🌐

NppFTP

FTP/SFTP远程文件编辑插件，支持直接连接服务器编辑远程文件，无需下载到本地。支持多个FTP站点管理。

推荐

Markdown Viewer

推荐

推荐
🔢

十六进制编辑插件，支持以十六进制方式查看和编辑文件，适合查看二进制文件、修改游戏存档等。

如何安装插件？

Notepad++ 插件安装非常简单，有两种方式：

方法一：通过插件管理器安装（推荐）

1. 打开 Notepad++，点击菜单栏的"插件" → "Plugin Manager" → "Show Plugin Manager"

2. 在"Available"标签页中找到需要的插件，勾选后点击"Install"

3. 重启 Notepad++ 即可使用新插件

方法二：手动安装

1. 下载插件压缩包（通常为 .zip 或 .dll 文件）

2. 解压后将 .dll 文件复制到 Notepad++ 安装目录下的 plugins 文件夹

3. 重启 Notepad++ 即可
