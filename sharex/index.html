三步开始使用

简单到不需要教程，几分钟即可上手

1

下载安装

从官网下载安装包或通过 Microsoft Store 安装，也可使用便携版免安装运行。

前往下载页面 →
2

配置快捷键

根据需要自定义截图、录屏、上传等快捷键，让操作更加顺手高效。

查看快捷键设置 →
3

开始使用

按下快捷键截图，自动上传并复制分享链接，整个流程一气呵成。

了解工作流 →

默认快捷键：Print Screen（全屏）| Ctrl + Print Screen（区域）| Shift + Print Screen（录屏）
