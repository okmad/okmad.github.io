强大的功能

ShareX 提供从截图到分享的完整解决方案，让效率触手可及

核心功能详解

从截图到分享，一气呵成

📸 截图模式

提供全屏、活动窗口、矩形区域、自由手绘、滚动窗口等多种截图方式，支持延迟截图、多显示器。

  • 滚动截图：一键截取长网页
  • 圆角/椭圆/多边形截图
  • 截图后自动打开编辑器
  • 支持自定义区域截图

🎨 图像编辑

内置强大的图像编辑器，支持标注、裁剪、添加水印、模糊、边框、特效等。

  • 箭头/矩形/圆形/文字标注
  • 高亮/马赛克/模糊特效
  • 自定义水印模板
  • 智能擦除与裁剪

🎬 屏幕录制

支持视频录制和 GIF 动图制作，可调节帧率、质量，支持音频录制。

  • 录制为 MP4、GIF
  • 支持 FFmpeg 编码调优
  • 光标高亮与点击效果
  • 区域选择与全屏录制

☁️ 文件上传

一键上传截图、文件至 80+ 服务，自动生成短链接，支持拖拽上传、右键上传。

  • Imgur / FTP / Dropbox
  • Google Drive / OneDrive
  • Amazon S3 / GitHub
  • 自定义上传目的地

🔤 OCR 文字识别

内置 Tesseract OCR 引擎，一键提取截图中中英文文本，支持复制、搜索与导出。

  • 支持中英文等多语言识别
  • 识别结果自动复制到剪贴板
  • 可导出为 TXT 文件
  • 支持识别整屏或区域

⚙️ 自动化工作流

通过任务配置实现全自动处理，节省重复劳动时间。

  • 截图后自动添加水印
  • 自动上传并复制链接
  • 支持命令行参数调用
  • 可配置多套工作流

实用工具集

内置 20+ 实用小工具，满足日常所需

🎨

拾色器

获取屏幕任意位置的颜色值，支持 RGB、HEX、HSL 等多种格式。

📏

屏幕标尺

测量屏幕上的像素距离，支持水平和垂直测量。

📌

屏幕贴图

将图片固定在屏幕顶层，方便对照参考，支持缩放与透明度。

🖼️

图像美化

一键美化截图，添加圆角、阴影、水印等效果。

🌈

图像特效

提供多种图像特效滤镜，如模糊、像素化、边缘检测等。

📊

二维码工具

生成或识别二维码，支持从截图或剪贴板读取。

#️⃣

哈希校验

计算文件的 MD5、SHA-1、SHA-256 等哈希值。

📋

剪贴板查看

📁

目录索引

🖼️

🎥

视频转换

🖥️

显示器测试

测试显示器坏点、颜色、对比度等性能。

后处理任务

截图后可自动执行的任务链，让工作流更高效

📤 截图后任务

截图完成后可自动执行：美化图像、添加特效、打开编辑器、复制到剪贴板、固定到屏幕、打印、保存文件等。

☁️ 上传后任务

上传完成后可自动执行：缩短 URL、分享链接、复制到剪贴板、打开浏览器、显示二维码等。

🔄 工作流系统

可创建多套工作流，针对不同场景一键切换，支持命令行调用与快捷键绑定。

⌨️ 快捷任务菜单

按下快捷键后弹出快速任务菜单，可选择本次截图要执行的任务，灵活应对不同需求。
