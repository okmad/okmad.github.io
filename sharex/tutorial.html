使用教程

从安装到高级使用，全面掌握 ShareX

快速入门

第一步：下载与安装

访问下载页面，选择适合您的版本（安装版或便携版）。双击安装包，按照向导提示完成安装。安装过程非常简单，通常只需要几秒钟。

💡 提示：首次启动 ShareX 时，会自动注册全局快捷键。如果被其他软件占用，可在"快捷键设置"中修改。

第二步：配置截图快捷键

ShareX 默认使用 Print Screen 键作为截图快捷键。您可以在"快捷键设置"中自定义所有快捷键，包括截图、录屏、上传等。

  • 打开 主菜单 → 快捷键设置
  • 为每种截图方式分配快捷键
  • 建议保留 Print Screen 作为主截图键

第三步：开始截图

按下快捷键即可开始截图。例如按 Print Screen 截取全屏，按 Ctrl + Print Screen 选择区域截图。截图完成后会自动执行配置好的后处理任务。

截图操作详解

📸 区域截图

按下区域截图快捷键后，屏幕会变暗并显示十字光标。按住鼠标左键拖动选择截图区域，松开鼠标完成截图。在选中区域上会显示工具栏，可使用标注工具进行编辑。

💡 小技巧：在区域截图模式下，可以按 空格键 切换到窗口捕获模式，点击窗口即可截取该窗口。

📜 滚动截图

滚动截图用于截取超长内容，如长网页、长文档等。启动滚动截图后，ShareX 会自动滚动页面并拼接截图，生成完整的长图。

  • 选择"滚动捕获"模式
  • 将鼠标移动到可滚动区域
  • ShareX 会自动滚动并截图
  • 按 Esc 键可手动停止

🎨 图像编辑

截图后可在编辑器中添加标注。编辑器提供矩形、椭圆、箭头、文字、马赛克等多种工具。

  • 选择工具后在截图上拖动绘制
  • 可在顶部工具栏调整颜色、粗细
  • 支持撤销/重做（Ctrl+Z / Ctrl+Y）
  • 编辑完成后点击保存或上传

录屏与 GIF 制作

录制屏幕视频或生成 GIF 动图

🎬 视频录屏

按下录屏快捷键，选择录制区域后开始录制。录制为 MP4 格式，支持音频同步录制。首次使用需安装 FFmpeg。

  • 选择录制区域或窗口
  • 可设置帧率（推荐 30fps）
  • 支持录制系统音频和麦克风
  • 按相同快捷键停止录制

🎞️ GIF 制作

GIF 录制与视频录屏操作类似，但输出为 GIF 动图格式，适合分享简短的操作演示。

  • 选择"GIF 录制"模式
  • 建议录制时长不超过 30 秒
  • 可调整帧率控制文件大小
  • 自动优化调色板减少体积

配置自动化工作流

让截图后的操作全自动完成

第一步：打开任务设置

在主菜单中点击 截图后任务 → 任务设置，进入任务配置界面。

第二步：配置截图后任务

在"图像"选项卡中，勾选您希望截图后自动执行的操作：

  • 保存图像到文件：自动保存到指定目录
  • 复制图像到剪贴板：方便粘贴到其他应用
  • 在图像编辑器中打开：手动编辑后再处理
  • 上传图像到主机：自动上传到云端
  • 执行操作：运行自定义脚本或命令

第三步：配置上传目的地

在"目的地"设置中，选择图片、文件、文本的上传目的地。例如将图片上传到 Imgur，文件上传到 FTP。

💡 推荐：对于个人使用，可将图片上传到 Imgur（免注册），文件上传到 GitHub Gist 或自建 FTP。

第四步：配置上传后任务

上传完成后可自动执行：缩短 URL、复制链接到剪贴板、在浏览器中打开、显示二维码等。

  • 复制 URL 到剪贴板：最常用，方便粘贴分享
  • 缩短 URL：使用短链接服务
  • 打开 URL：在浏览器中查看上传结果
  • 显示二维码：方便手机扫码访问

OCR 文字识别

一键提取图片中的文字

🔤 使用 OCR

ShareX 内置 Tesseract OCR 引擎，可识别图片中的中英文文字。

  1. 截图或打开一张图片
  2. 在主菜单选择 工具 → OCR
  3. 首次使用会提示下载 OCR 语言包
  4. 识别完成后文字自动复制到剪贴板

🌐 支持的语言

可下载多种语言包，支持中英文混合识别。

  • 简体中文（chi_sim）
  • 繁体中文（chi_tra）
  • 英文（eng）
  • 日文（jpn）等多种语言

高级设置

⚙️ 开机自启动

在 主菜单 → 应用设置 → 常规 中，勾选"开机时运行 ShareX"，即可实现开机自启动。

🎨 自定义水印

在 任务设置 → 图像 → 水印 中，可添加图片或文字水印，支持位置、透明度、边距等自定义。

📁 文件命名规则

在 应用设置 → 文件命名 中，可自定义截图文件的命名规则，支持时间戳、计数器、自定义文本等变量。

🔄 多工作流配置

在 工作流设置 中，可创建多套工作流，每套工作流可绑定不同快捷键，应对不同场景。

📤 自定义上传器

在 目的地 → 自定义上传器 中，可添加自定义的 API 上传服务，支持各种图床与云存储。
