安装与下载

LibreOffice 是否完全免费？
是的，LibreOffice 是完全免费的开源软件，遵循 MPL 2.0 协议。您可以免费下载、使用和分发，无任何隐藏费用或限制。软件不包含任何广告或捆绑软件。个人用户、企业用户、政府机构均可免费使用。The Document Foundation 不提供任何付费版本。
LibreOffice 支持哪些操作系统？
LibreOffice 原生支持三大桌面平台：

• Windows：Windows 10 / 11（64 位、32 位、ARM64）
• macOS：macOS 11 Big Sur 或更高，支持 Apple Silicon 和 Intel 双架构
• Linux：Ubuntu、Debian、Fedora、CentOS、openSUSE、Arch 等，提供 deb、rpm、Flatpak、Snap 多种安装方式
• 其他：FreeBSD、NetBSD 等 BSD 系统也有社区支持版本
如何确认下载的是正版 LibreOffice？
请仅通过以下官方渠道获取 LibreOffice：

1. 官方网站 libreoffice.org
2. 中文官网 zh-cn.libreoffice.org
3. 中文社区 libreoffice.org.cn
4. 本中文网站提供的下载链接（均指向官方 CDN download.documentfoundation.org）

避免从第三方下载站获取，以免下载到捆绑广告软件或恶意程序的版本。所有官方发布版本均经过数字签名。
安装后界面是英文怎么办？
LibreOffice 支持多语言，包括简体中文。设置方法：

1. 打开 LibreOffice。
2. 进入"Tools → Options → Language Settings → Languages"。
3. 在"User Interface"中选择"简体中文"。
4. 点击"OK"，重启 LibreOffice 即可显示中文界面。

如果列表中没有简体中文，需要下载并安装中文语言包（Language Pack）。
LibreOffice 和 OpenOffice 有什么区别？
LibreOffice 是 OpenOffice.org 的分支版本，于 2010 年分叉。

主要区别：
• 开发活跃度：LibreOffice 由 The Document Foundation 维护，开发非常活跃，更新频繁；OpenOffice 自 2014 年后更新缓慢。
• 功能：LibreOffice 功能更丰富，支持更多格式和扩展。
• 兼容性：LibreOffice 对 Microsoft Office 文档的兼容性更好。
• 社区：LibreOffice 拥有更庞大的社区和贡献者。

建议使用 LibreOffice 而非 OpenOffice。
如何获取旧版本 LibreOffice？
如果您需要旧版本 LibreOffice，可以访问官方存档下载中心：

https://downloadarchive.documentfoundation.org/libreoffice/old/

这里包含所有历史版本的 LibreOffice。注意：旧版本可能不再受支持，存在安全风险，建议仅在必要时使用。

Windows XP 用户：最后一个支持 Windows XP 的版本是 5.4.7。

文档兼容性

LibreOffice 能打开 Microsoft Office 文档吗？
可以。LibreOffice 完美兼容 Microsoft Office 文档格式：

• Word 文档：支持打开和保存 DOC、DOCX、RTF 格式
• Excel 表格：支持打开和保存 XLS、XLSX、CSV 格式
• PowerPoint 演示：支持打开和保存 PPT、PPTX 格式
• Visio 绘图：支持打开 VSD、VSDX 格式
• Access 数据库：支持打开 ACCDB、MDB 格式

对于复杂的 Office 文档，部分高级格式（如某些宏、SmartArt）可能显示略有差异，但基本内容完整保留。
应该使用 ODF 还是 Office 格式保存？
建议根据使用场景选择：

使用 ODF 格式（推荐）：
• ODT、ODS、ODP 是国际标准格式（ISO/IEC 26300）
• 文档长期可读，不被锁定在专有格式中
• 文件通常更小，加载更快
• 适合个人使用和长期归档

使用 Office 格式：
• 需要与 Microsoft Office 用户协作时
• 提交给要求 Office 格式的机构
• 兼容旧版 Office 用户

可在"工具 → 选项 → 加载/保存 → 常规"中设置默认保存格式。
为什么打开 DOCX 文档格式有些错乱？
DOCX 是 Microsoft 的专有格式，部分高级功能 LibreOffice 可能无法完全还原。解决方法：

1. 使用最新版本：升级到最新版 LibreOffice，兼容性持续改进。
2. 使用 ODF 格式：如果可能，使用 ODT 格式保存文档，避免格式转换损失。
3. 嵌入字体：在保存时嵌入字体，确保跨设备显示一致。
4. 导出为 PDF：如果只需查看，导出为 PDF 可保留原始排版。
5. 手动调整：打开后手动调整格式，使用样式而非直接格式。
如何将文档导出为 PDF？
导出 PDF 的方法：

1. 打开要导出的文档。
2. 选择"文件 → 导出为 → 导出为 PDF"。
3. 在弹出的 PDF 选项对话框中设置：
   • 常规：页面范围、图像质量、压缩
   • 初始视图：打开时的视图模式、缩放
   • 用户界面：窗口选项、书签可见性
   • 链接：链接行为、导出书签
   • 安全性：设置打开密码、权限密码
4. 点击"导出"按钮，选择保存位置即可。

也可使用快捷键 Ctrl+Shift+S 另存为时选择 PDF 格式。

使用问题

如何启用自动保存？
启用自动保存的方法：

1. 进入"工具 → 选项 → 加载/保存 → 常规"。
2. 勾选"保存自动恢复信息时间间隔"。
3. 设置时间间隔（建议 5-10 分钟）。
4. 可选：勾选"自动保存时覆盖原文件"。
5. 点击"确定"保存设置。

启用后，LibreOffice 会定期自动保存文档副本，意外关闭时可恢复。
如何安装扩展（插件）？
安装扩展的方法：

方法一：通过扩展管理器
1. 进入"工具 → 扩展管理器"。
2. 点击"添加"按钮。
3. 选择下载的 .oxt 扩展文件。
4. 按提示完成安装。

方法二：双击安装
直接双击 .oxt 文件，LibreOffice 会自动打开扩展管理器安装。

获取扩展：
访问官方扩展库 https://extensions.libreoffice.org/ 下载扩展。
如何使用宏自动化任务？
LibreOffice 支持多种宏语言：

录制宏：
1. 进入"工具 → 宏 → 录制宏"。
2. 执行要录制的操作。
3. 点击"停止录制"，保存宏。

编写宏：
1. 进入"工具 → 宏 → 编辑宏"。
2. 在宏编辑器中编写 Basic 代码。
3. 也可使用 Python、BeanShell、JavaScript。

示例（Basic）：
Sub HelloWorld
   MsgBox "Hello, World!"
End Sub
如何更改默认字体？
更改默认字体的方法：

Writer：
1. 进入"工具 → 选项 → LibreOffice Writer → 基本字体"。
2. 修改默认、标题、列表等字体。
3. 点击"确定"保存。

Calc：
1. 进入"工具 → 选项 → LibreOffice Calc → 默认字体"。
2. 修改默认字体。

也可通过修改默认模板实现：创建文档设置好格式，"文件 → 模板 → 保存为模板"，设为默认模板。
如何使用邮件合并功能？
邮件合并用于批量生成信函、信封、标签：

1. 准备数据源：创建 Calc 表格或 CSV 文件，包含姓名、地址等字段。
2. 创建主文档：在 Writer 中创建文档模板。
3. 连接数据源：进入"工具 → 邮件合并向导"。
4. 选择数据源：浏览并选择准备好的数据文件。
5. 插入字段：在文档中插入数据字段（如《姓名》）。
6. 预览：预览合并效果。
7. 输出：保存为单独文档、打印或发送邮件。

技术问题

LibreOffice 启动慢怎么办？
加速启动的方法：

1. 禁用快速启动：在"工具 → 选项 → LibreOffice → 常规"中取消"启动时显示启动屏幕"。
2. 禁用扩展：禁用不必要的扩展，减少加载时间。
3. 禁用 Java：如果不使用 Java 功能，在"工具 → 选项 → LibreOffice → 高级"中取消"使用 Java 运行时环境"。
4. 使用 SSD：将 LibreOffice 安装在 SSD 上，启动更快。
5. 增加内存：在"工具 → 选项 → LibreOffice → 内存"中调整缓存设置。
如何解决字体显示问题？
字体显示问题的解决方法：

1. 安装字体：确保系统安装了文档使用的字体。
2. 嵌入字体：保存文档时嵌入字体（文件 → 属性 → 字体 → 嵌入字体）。
3. 字体替换：在"工具 → 选项 → LibreOffice → 字体"中设置字体替换规则。
4. 安装中文字体：安装思源黑体、思源宋体等开源中文字体。
5. 使用跨平台字体：使用 Arial、Times New Roman 等跨平台字体。
如何修复损坏的文档？
修复损坏文档的方法：

1. 自动修复：LibreOffice 打开损坏文档时会提示修复，点击"是"尝试修复。
2. 手动修复：进入"文件 → 打开"，选择文件后点击"打开"按钮旁的下拉箭头，选择"打开并修复"。
3. 从备份恢复：查看"工具 → 选项 → LibreOffice → 路径 → 备份"目录中的备份文件。
4. 从临时文件恢复：查看系统临时目录中的 .tmp 文件。
5. 使用 zip 工具：ODF 文档是 zip 压缩包，可解压后查看内容。
如何配置代理服务器？
配置代理服务器的方法：

1. 进入"工具 → 选项 → LibreOffice → 互联网"。
2. 在"代理"部分选择：
   • 无代理：不使用代理
   • 系统代理：使用系统代理设置
   • 手动配置：手动填写代理服务器地址和端口
3. 设置 HTTP 代理和 HTTPS 代理。
4. 配置不使用代理的主机（如 localhost）。
5. 点击"确定"保存设置。

其他问题

LibreOffice 还会继续更新吗？
LibreOffice 仍在持续活跃开发中。The Document Foundation 拥有全球最活跃的开源办公套件社区，定期发布新版本，不断优化性能并添加新功能。最新版本 26.2.4 于 2026 年 6 月发布。建议始终使用最新稳定版以获得最佳体验。

LibreOffice 每年发布多个版本，包括：
• 新鲜版（Fresh）：包含最新功能，适合尝鲜用户
• 稳定版（Still）：经过长期测试，适合企业环境

5. 设计：参与 UI/UX 设计、图标设计。
6. 质量保证：参与测试，验证 Bug 修复。

访问 https://www.libreoffice.org/community/ 参与开发。
LibreOffice 支持哪些文档格式？
LibreOffice 支持丰富的文档格式：

开放文档格式（ODF）：ODT、ODS、ODP、ODG、ODF、ODB
Microsoft Office：DOC、DOCX、XLS、XLSX、PPT、PPTX、VSD、VSDX、ACCDB、MDB
其他办公格式：RTF、CSV、DBF、WPS、PAGES
图像格式：PNG、JPEG、GIF、BMP、TIFF、SVG、EPS
网页格式：HTML、XHTML
电子书：EPUB、FB2
PDF：导入和导出 PDF
数学公式：MathML、LaTeX

LibreOffice 和 WPS Office 有什么区别？
LibreOffice：
• 完全免费开源（MPL 2.0 协议）
• 无广告、无捆绑软件
• 跨平台支持（Windows、macOS、Linux）
• 由全球社区维护，开发透明
• 支持 ODF 国际标准格式
• 功能专业，适合企业和政府

WPS Office：
• 免费版含广告，专业版收费
• 闭源商业软件
• 主要支持 Windows、macOS、移动端
• 界面与 Microsoft Office 相似
• 中文本地化更完善

建议追求开源、免费、跨平台的用户选择 LibreOffice。
