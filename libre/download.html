⚙️ 版本说明

Windows 64位：适用于 Windows 10/11（64位），推荐大多数用户使用。
Windows ARM64：适用于 Windows on ARM 设备，如搭载骁龙芯片的 Surface 笔记本。
macOS Apple Silicon：适用于 M1/M2/M3/M4 芯片的 Mac，原生 ARM 架构，性能最佳。
macOS Intel：适用于 Intel 芯片的 Mac。
Linux deb：适用于 Ubuntu、Debian、Linux Mint 等 Debian 系发行版。
Linux rpm：适用于 Fedora、CentOS、openSUSE 等 Red Hat 系发行版。

安装步骤

1

下载安装包

点击上方下载按钮，获取对应平台的安装包。

2

运行安装程序

Windows：双击 MSI 安装。macOS：打开 DMG 拖入应用程序。Linux：使用包管理器安装。

3

完成安装

等待安装进度完成，从开始菜单或应用程序文件夹启动 LibreOffice。

4

开始使用

LibreOffice 默认支持简体中文界面，启动后即可开始办公。
