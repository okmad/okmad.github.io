功能介绍

LibreOffice 提供完整的办公生产力工具，包含六大组件，覆盖文档处理、数据分析、演示制作、绘图设计、数据库管理、公式编辑等所有办公场景。

六大核心组件

LibreOffice 包含六大功能组件，每个组件都经过精心设计，满足专业办公需求。

📝 Writer 文字处理

功能强大的文字处理器，从快速笔记到长篇书籍都能胜任。支持样式、目录、索引、邮件合并、修订跟踪等专业功能。

核心功能：
• 样式与模板：完整的段落样式、字符样式、页面样式、列表样式系统，支持自定义模板。
• 目录与索引：自动生成目录、图表目录、索引、书目引用，支持多级目录。
• 邮件合并：批量生成信函、信封、标签，支持数据源连接。
• 修订跟踪：记录文档修改，支持批注、比较、合并文档。
• 宏与扩展：支持 LibreOffice Basic、Python、BeanShell、JavaScript 宏语言。
• 导出格式：支持导出 PDF、EPUB、HTML、纯文本等格式。
• 兼容性：完美兼容 DOC、DOCX、RTF、ODT 等文档格式。

📊 Calc 电子表格

功能丰富的电子表格应用，用于分析数据、处理数字、创建清晰的可视化图表。

核心功能：
• 公式与函数：支持 500+ 内置函数，包括数学、统计、财务、日期时间、文本处理等。
• 数据透视表：强大的数据分析工具，支持多维数据汇总、筛选、排序。
• 图表：支持柱状图、折线图、饼图、散点图、雷达图等多种图表类型。
• 条件格式：根据单元格值自动应用格式，数据条、色阶、图标集。
• 场景管理：保存多组输入值，快速切换不同假设场景。
• 多用户协作：支持共享工作簿，多人同时编辑。
• 兼容性：完美兼容 XLS、XLSX、ODS、CSV 等格式。
• 数据处理：支持 104 万行 × 1024 列，处理大型数据集。

📽️ Impress 演示文稿

轻松快速地创建引人入胜的多媒体演示文稿。

核心功能：
• 母版与布局：使用母版统一设计风格，支持多种版式布局。
• 动画效果：支持入场、强调、退出、路径动画，自定义动画顺序。
• 幻灯片切换：丰富的切换效果，支持淡入淡出、推入、旋转等。
• 多媒体：插入图片、音频、视频、动画 GIF，支持多种媒体格式。
• 自定义放映：创建多个放映方案，针对不同受众展示不同内容。
• 演示者视图：双屏显示，演示者可看到备注、计时、下一张幻灯片。
• 导出：支持导出 PDF、HTML、SWF、图片，或导出为视频。
• 兼容性：完美兼容 PPT、PPTX、ODP 等格式。

🎨 Draw 绘图工具

从简单图表到复杂 3D 插图的设计工具。

核心功能：
• 矢量绘图：基于矢量的绘图工具，可无损缩放，适合制作 Logo、图标、插图。
• 形状库：丰富的预设形状，包括矩形、椭圆、箭头、流程图、星形等。
• 3D 对象：创建和编辑 3D 立体对象，支持光照、材质、旋转。
• 连接线：智能连接线，移动形状时自动调整，适合绘制流程图。
• 图层管理：多图层支持，可锁定、隐藏、调整图层顺序。
• 贝塞尔曲线：专业的贝塞尔曲线编辑工具，绘制复杂路径。
• 网格与对齐：网格、参考线、对齐工具，精确绘图。
• 导出格式：支持导出 SVG、PDF、PNG、EPS、BMP 等格式。

🗄️ Base 数据库

直接管理数据库：在一个地方构建表、表单、查询和报表。

核心功能：
• 数据库引擎：内置 HSQLDB 引擎，支持创建本地数据库文件。
• 外部数据库：连接 MySQL、PostgreSQL、Oracle、Microsoft Access、dBASE 等。
• 表设计：可视化表设计器，定义字段类型、主键、索引、关系。
• 查询设计：可视化查询构建器，支持 SQL 视图直接编写 SQL。
• 表单设计：拖拽式表单设计器，创建数据录入和浏览界面。
• 报表设计：可视化报表设计器，生成专业报表，支持分组、汇总。
• 关系视图：图形化关系编辑器，定义表间关系。
• 宏编程：使用 Basic 或 Python 编写数据库应用程序。

🔢 Math 公式编辑

使用可视化编辑器或纯文本轻松编写数学公式。

核心功能：
• 公式输入：使用简单的文本语法编写公式，如 a^2 + b^2 = c^2。
• 可视化编辑：公式编辑器实时预览，所见即所得。
• 符号库：丰富的数学符号库，包括希腊字母、运算符、关系符等。
• 嵌入使用：可嵌入 Writer、Impress、Calc、Draw 文档中。
• 独立使用：可作为独立应用创建公式文件。
• 导出：支持导出为 MathML、LaTeX、PDF、PNG 等格式。
• 兼容性：支持导入 Microsoft Equation Editor 公式。

通用功能

所有组件共享的强大功能，提升办公效率。

01

宏与扩展

支持 LibreOffice Basic、Python、BeanShell、JavaScript 等多种宏语言。可通过扩展管理器安装第三方扩展，增强功能。

02

PDF 导出

所有组件均支持导出为 PDF 格式，可设置密码保护、压缩、嵌入字体、添加水印等选项。

03

多语言支持

支持全球数十种语言界面，包括简体中文、繁体中文。提供拼写检查、同义词库、断字等功能。

04

模板系统

丰富的内置模板，支持自定义模板。可从官方模板库下载更多模板，快速创建专业文档。

05

版本控制

支持文档修订跟踪、版本管理、文档比较。适合团队协作和文档审核。

06

无障碍功能

支持屏幕阅读器、键盘导航、高对比度模式。符合 WCAG 2.1 标准，确保所有用户都能使用。

使用技巧

掌握这些技巧，让 LibreOffice 使用更高效。

1

使用样式而非直接格式

使用段落样式、字符样式管理文档格式，修改样式即可批量更新文档外观，比直接格式更高效、更一致。

2

启用自动保存

在"工具 → 选项 → 加载/保存 → 常规"中启用自动保存，设置间隔时间（建议 5-10 分钟），防止数据丢失。

3

使用模板

为常用文档类型创建模板（报告、简历、发票等），新建文档时选择模板，节省排版时间。

4

掌握快捷键

学习常用快捷键，如 Ctrl+S 保存、Ctrl+Z 撤销、Ctrl+F 查找、F5 演示、F11 样式和格式等，提升操作效率。

5

安装扩展

从官方扩展库下载实用扩展，如 PDF Import（导入 PDF 编辑）、LanguageTool（语法检查）等，增强功能。

6

使用 ODF 格式

默认使用 ODF 格式（ODT、ODS、ODP）保存文档，这是国际标准格式，确保文档长期可读，不被锁定在专有格式中。
