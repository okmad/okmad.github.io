什么是 PuTTY？

历经 28 年持续更新的开源远程连接标杆

最经典的免费 SSH 远程登录客户端

PuTTY 是由英国开发者 Simon Tatham 主导开发的一款开源免费远程连接工具，自 1998 年发布第一版以来持续维护更新超过 28 年，是全球使用最广泛的 Windows 平台 SSH 客户端之一。它最初为 Windows 平台设计，通过移植版本也可运行于 Linux、macOS 等系统，采用 MIT 开源许可证发布，源码完全公开。

PuTTY 支持 SSH、Telnet、Rlogin、串口（Serial）以及原始 TCP 等多种连接方式：无论是管理云服务器、VPS 主机，还是调试路由器、交换机等网络设备，甚至连接开发板、工控机的串口控制台，PuTTY 都能胜任。它全面支持 SSH1 与 SSH2 协议、公钥/密钥认证、AES 等主流加密算法、X11 转发与端口转发、IPv6 连接，并完整模拟 xterm、VT102、ECMA-48 终端行为。

软件本体体积仅约 3MB、绿色免安装、无广告无捆绑，所有配置操作都集中在一个窗口的控制面板中完成，简单直观。下载解压后双击 putty.exe 即可使用，也可放入 U 盘随身携带，是运维工程师、站长、开发者的装机必备工具。本站提供的 中文版基于官方源码完整汉化编译，界面全中文、原生支持 UTF-8 中文显示，让远程管理服务器更加得心应手。

PuTTY 使用教程：五步连接 Linux 服务器

零基础也能快速上手，双击即用无需安装

1

下载并解压运行

在本站下载 PuTTY 中文版完整组件包，解压后双击 putty.exe 直接运行。绿色免安装，不需要任何安装步骤，也不会写注册表。

2

填写服务器 IP 与端口

在 Session 页面的 Host Name 栏填写服务器公网 IP 或域名，Port 保持默认 22，Connection type 选择 SSH 协议。

3

保存会话并连接

在 Saved Sessions 输入名称（如"我的服务器"）点击 Save 保存，然后点击 Open。首次连接会提示主机密钥确认，选择"接受"即可。

4

输入账号密码登录

在终端窗口 login as 后输入用户名（如 root）回车，再输入密码（输入时屏幕不显示任何字符，属正常安全设计）回车完成登录。

5

下次一键快速登录

之后再次使用时，选中保存的会话名称，点击 Load 载入配置后点 Open，即可跳过重复配置一键登录服务器命令行。

PuTTY 实用技巧

老司机都在用的效率技巧，让你的远程操作更顺手

🈶

解决中文显示乱码

右键标题栏打开 Change Settings，进入 Window - Translation，将 Remote character set 设为 UTF-8，中文即可正常显示。中文版已默认 UTF-8，一般无需手动设置。

🎨

修改字体与配色

在 Appearance 中点击 Font settings - Change 可调整字体、字形与大小；在 Colours 中可自定义前景色、背景色与 ANSI 配色，打造舒适护眼的终端主题。

📝

开启会话日志记录

在 Session - Logging 中选择 All session output，设置日志文件保存路径，即可完整记录每次操作的输入输出，方便审计与回溯问题。

🔑

密钥免密码登录

用 puttygen.exe 生成密钥对，公钥写入服务器 ~/.ssh/authorized_keys，私钥用 pageant 加载，之后所有会话自动免密码登录，安全又高效。

⌨️

常用快捷键

Shift+PgUp / PgDn 快速翻页查看回滚内容；Ctrl+L 清屏；Ctrl+A / Ctrl+E 跳转行首行尾；Ctrl+W 删除左侧单词；Ctrl+Y 粘贴已删除内容。

📋

复制粘贴技巧

鼠标左键拖选即自动复制（无需按 Ctrl+C），右键单击即直接粘贴；配合 Window - Selection 设置可调整选择行为，命令行操作效率翻倍。

PuTTY 常见问题（FAQ）

关于 PuTTY 下载、使用与安全的常见疑问解答

PuTTY 是免费的吗？需要安装吗？

PuTTY 完全免费且开源（MIT 许可证），无广告、无捆绑、无需注册。它是绿色免安装软件，下载解压后双击 putty.exe 即可使用，也可以放在 U 盘中随身携带。

PuTTY 中文版和官方英文版有什么区别？

中文版由开发者基于官方源码进行完整汉化编译，界面全中文显示，并默认采用 UTF-8 代码页以更好支持中文显示。核心功能与官方版完全一致，推荐 Windows 10/11 用户使用 0.85 中文版。

PuTTY 连接后中文显示乱码怎么办？

右键窗口标题栏打开 Change Settings，进入 Window - Translation，将 Remote character set 设置为 UTF-8 即可正常显示中文。同时建议确认服务器系统默认编码为 UTF-8，中文版默认即为 UTF-8 一般无需手动调整。

输入密码时屏幕没有显示任何字符，是故障吗？

不是故障，这是 Linux 终端的安全设计。输入密码时屏幕故意不回显任何内容（连 * 号也不显示），你只需正常输入密码后按回车即可完成登录。

PuTTY 和 XShell 哪个更好用？

PuTTY 免费开源、体积极小、绿色免安装，适合个人用户与轻量运维；XShell 界面更现代、多标签管理更强，但闭源且部分场景需要授权。如果只需要快速 SSH 登录服务器，PuTTY 是最轻量可靠的选择，两者也可以同时安装互补使用。

PuTTY 0.85 支持哪些系统？旧电脑能用吗？

0.85 中文版默认 UTF-8 代码页编译，仅支持 Windows 10/11，提供 x64、Win32、ARM64 三种架构。旧系统（Windows 7/8/XP）用户可下载 0.78 及更早历史版本使用，本站下载页提供历史版本归档。

PuTTY 支持文件上传下载吗？

支持。组件包中的 PSCP（命令行 SCP 拷贝）与 PSFTP（交互式 SFTP 客户端）均可完成服务器与本地之间的文件传输；如果习惯图形化操作，可以配合 WinSCP（底层同样基于 PuTTY）使用。

用 PuTTY 连接服务器安全吗？会不会泄露密码？

安全。PuTTY 的 SSH 连接全程加密，并具备严格的主机密钥校验机制，可防止中间人攻击。建议配合密钥认证使用，并始终从可信渠道下载 PuTTY 安装包，避免使用来历不明的修改版。
