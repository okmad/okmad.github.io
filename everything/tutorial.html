使用教程

从安装到高级使用，全面掌握 Everything

快速入门

第一步：下载与安装

访问下载页面，选择适合您的版本（安装版或便携版）。双击安装包，按照向导提示完成安装。安装过程非常简单，通常只需要几秒钟。

💡 提示：首次安装时，Everything 会自动建立文件索引。索引完成后即可开始搜索。

第二步：基本搜索

启动 Everything 后，在搜索框中输入关键词即可开始搜索。搜索结果会实时显示，无需按回车键。例如：

  • 输入 document 搜索包含"document"的文件
  • 输入 *.pdf 搜索所有 PDF 文件
  • 输入 photo.jpg 搜索名为"photo.jpg"的文件

第三步：打开文件

在搜索结果中双击文件即可打开。右键点击文件可以查看更多选项，如打开所在文件夹、复制路径等。

通配符搜索

*

星号通配符

匹配任意数量的字符

*.docx
搜索所有 Word 文档

?

问号通配符

匹配单个字符

photo?.jpg
搜索 photo1.jpg, photo2.jpg

📁

文件夹搜索

搜索特定文件夹

project*
搜索所有 project 开头的文件夹

📄

文件类型

按扩展名搜索

*.mp3
搜索所有音频文件

高级搜索技巧

多关键词搜索

使用空格分隔多个关键词，搜索同时包含这些词的文件。

report 2024 pdf

搜索同时包含"report"、"2024"和"pdf"的文件

排除搜索

使用感叹号 ! 排除特定关键词。

document !temp

搜索包含"document"但不包含"temp"的文件

精确搜索

使用引号搜索精确短语。

"final report"

搜索精确包含"final report"这个短语的文件

逻辑运算符

使用 AND、OR、NOT 进行复杂搜索。

  • file AND (doc OR pdf) - 搜索包含"file"且是 doc 或 pdf 格式的文件
  • image NOT (jpg OR png) - 搜索包含"image"但不是 jpg 或 png 的文件
  • (project OR work) AND 2024 - 搜索包含"project"或"work"，且包含"2024"的文件

文件属性搜索

根据文件大小、日期等属性进行搜索。

  • size:>10mb - 搜索大于 10MB 的文件
  • size:<1mb - 搜索小于 1MB 的文件
  • datemodified:today - 搜索今天修改的文件
  • datecreated:lastweek - 搜索上周创建的文件

常用快捷键

Ctrl + F 聚焦搜索框
Ctrl + L 清空搜索框
Ctrl + Enter 打开文件所在位置
Ctrl + C 复制文件路径
Ctrl + A 全选搜索结果
F3 高级搜索
Esc 清空搜索框
Ctrl + P 打开选项设置

设置与优化

开机自动启动

在"工具" > "选项" > "常规"中，勾选"启动时运行 Everything"，这样每次开机时 Everything 会自动启动并建立索引。

排除文件夹

在"工具" > "选项" > "索引" > "排除"中，添加不想索引的文件夹路径，如临时文件夹、系统文件夹等。

更换语言

下载并安装中文语言包后，在"工具" > "选项" > "常规"中，从"语言"下拉菜单选择"中文（简体）"。

自定义界面

在"工具" > "选项" > "界面"中，可以调整字体大小、颜色主题、列显示等，打造个性化的搜索体验。

重建索引

如果搜索不到某些文件，可以尝试重建索引。在"工具"菜单中选择"重建索引"，Everything 会重新扫描所有文件。
