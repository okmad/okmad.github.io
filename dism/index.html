什么是 Dism++？

Dism++ 是一款由初雨团队采用微软内部 API 编写的开源免费实用工具，最初名为"Windows 更新清理工具"。它基于 CBS（Component Based Servicing）底层实现，不依赖 DISM.exe，提供完全的图形化操作界面，几乎支持 DISM 的所有功能以及大量 DISM 原本不支持的特性。

🟢 完全免费开源

遵循 MIT 协议，代码公开透明，无任何隐藏费用或广告插件。代码托管在 GitHub，由初雨团队与社区共同维护，规则库与语言包持续更新。

🟢 绿色便携

单文件设计，解压即用，不写入注册表，U 盘随身携带。32 位版约 3.5 MB，64 位版约 4.2 MB。不依赖 .NET 或其他运行库。

🟢 功能全面

集清理、优化、备份、驱动管理、镜像处理于一体。整合了系统清理、更新管理、驱动管理、Appx 应用管理、系统备份还原等众多功能。

🟢 安全可靠

调用系统原生 API，通过主流杀软检测，拥有正规数字签名。无广告、无捆绑、无全家桶，全程绿色不流氓。

🟢 持续更新

初雨团队长期维护，不断适配新版 Windows 及扩充清理规则。项目自 2011 年发布至今持续更新，已有 10 年以上的活跃开发历史。

🟢 API 级别底层

直接基于 CBS 核心，不依赖 DISM.exe，实现更底层的系统操作与更快的响应速度。解锁微软隐藏的系统功能，如 ESD 捕获、ESD 转 WIM 等。

简单几步，掌握 Dism++ 的使用方法
