安装与下载

Dism++ 是否完全免费？
是的，Dism++ 是完全免费的开源软件，采用 MIT 许可证。您可以免费下载、使用和分发，无任何隐藏费用或限制。软件不包含任何广告、捆绑软件或恶意代码，完全由开发者用爱发电。
Dism++ 支持哪些 Windows 版本？
Dism++ 支持从 Windows Vista 到 Windows 11 的所有版本，还支持最新的 ARM 架构。涵盖 x86（32位）、x64（64位）、ARM 等处理器架构。一个工具解决不同系统版本的兼容性问题。
使用 Dism++ 需要安装吗？
不需要安装。Dism++ 是绿色便携软件，下载 ZIP 压缩包后解压到任意文件夹，双击 Dism++x64.exe 或 Dism++x86.exe 即可直接运行，不会在系统中留下注册表项或其他痕迹。32 位版约 3.5 MB，64 位版约 4.2 MB，非常适合放入 U 盘随身携带。
应该下载 32 位还是 64 位版本？
如果您的系统是 64 位 Windows（现在大多数电脑都是），请下载 64 位版本（Dism++x64.exe）。如果您的系统是 32 位 Windows，请下载 32 位版本（Dism++x86.exe）。查看方法：右键"此电脑"→"属性"→"系统类型"。
为什么需要管理员权限运行？
Dism++ 需要执行系统级操作，如清理系统文件、管理驱动、修复系统映像等，这些操作需要管理员权限才能完成。请右键点击程序，选择"以管理员身份运行"。
wsusscn3.cab 是什么？如何使用？
wsusscn3.cab 是 Windows 更新扫描所需的数据包。下载后将其放在 Dism++ 的 Config 目录中，更新扫描功能即可正常使用。从 v10.1.1002.1 版本开始，Dism++ 支持基于 GitHub 服务自动更新 wsusscan3.cab，无需手动下载。

使用与功能

Dism++ 与原生 DISM 有什么区别？
Dism++ 提供图形化界面，功能更丰富，操作更简单。基于 CBS 底层 API 开发，兼容性更好，还提供了微软隐藏的高级功能。主要区别：

1. 图形化界面：Dism++ 提供完全的图形化操作界面，无需记忆复杂命令。
2. 不依赖 DISM.exe：直接调用 CBS 核心 API，兼容性更好。
3. 更多功能：提供系统优化、启动项管理、Appx 管理等 DISM 不支持的功能。
4. 解锁隐藏功能：如 ESD 捕获、ESD 转 WIM 等微软隐藏的高级功能。
如何清理 C 盘空间？
使用 Dism++ 的"空间回收"功能可以深度清理 C 盘：

1. 打开 Dism++，选择左侧的"空间回收"。
2. 勾选需要清理的项目（建议勾选 Windows 更新清理、WinSxS 组件清理、系统临时文件等）。
3. 点击"清理"按钮开始扫描并清理。

实测可释放 3-30GB 空间，比系统自带的磁盘清理工具更彻底。如果空间仍然不足，可以考虑开启 CompactOS 压缩功能。
CompactOS 是什么？应该开启吗？
CompactOS 是 Windows 10/11 提供的系统压缩功能，通过压缩系统文件来节省硬盘空间，通常可节省 2-6GB 空间。

建议开启的情况：硬盘空间紧张（如 128GB SSD），CPU 性能较强。
不建议开启的情况：SSD 空间充足，CPU 性能较弱，因为压缩会增加 CPU 负担，可能影响系统响应速度。
如何卸载 Windows 预装应用？
使用 Dism++ 的"Appx 管理"功能：

1. 打开 Dism++，选择左侧的"Appx 管理"。
2. 在右侧列表中会显示所有已安装的 UWP 应用。
3. 勾选要卸载的应用（如"获取帮助"、"Mixed Reality"等无法通过系统设置卸载的应用）。
4. 点击"删除"按钮即可强制移除。
如何备份和还原驱动？
使用 Dism++ 的"驱动管理"功能：

备份驱动：选择"驱动管理"→勾选要备份的驱动→点击"导出"选择保存路径。
还原驱动：重装系统后，选择"驱动管理"→点击"添加"→选择之前备份的驱动文件夹→安装即可。

建议在系统正常时备份所有驱动，以便重装系统后快速恢复。
如何创建系统备份？
使用 Dism++ 工具箱中的"系统备份"功能：

1. 打开 Dism++，进入"工具箱"。
2. 选择"系统备份"。
3. 选择保存路径和备份格式（推荐 ESD 格式，压缩率更高）。
4. 点击"开始"即可在系统运行时完成热备份，无需进入 PE。

建议定期备份系统，以便出现问题时快速恢复。
什么是"春哥附体"模式？
"春哥附体"（God Mode）是 Dism++ 提供的一种特殊的崩溃保护模式。即使在系统资源极度匮乏、其他程序无法运行的情况下，也能强行运行 Dism++ 进行系统修复。

当系统出现严重问题、常规方式无法启动 Dism++ 时，可以尝试使用此模式进行应急修复。
如何在 PE 环境下使用 Dism++？
Dism++ 可以在 PE 环境下运行，用于离线系统维护：

1. 将 Dism++ 程序文件加入 PE 启动盘（如微 PE、优启通等）。
2. 从 PE 启动盘启动电脑。
3. 运行 Dism++，即可对离线系统进行清理、修复、驱动管理等操作。

这在系统无法正常启动时非常有用，可以修复系统文件、清理垃圾、管理驱动等。

安全性与对比

使用 Dism++ 是否安全？
完全安全。Dism++ 是开源软件，代码公开透明，已通过主流杀毒软件检测，不包含任何恶意代码或广告。软件拥有正规数字签名认证，确保来源可信、完整未被篡改。

此外，Dism++ 调用系统原生 CBS API，不修改系统核心文件，清理逻辑经过多年发展非常成熟，误删系统文件的风险极低。
Dism++ 会损坏系统吗？
正常使用情况下不会损坏系统。Dism++ 的清理规则经过多年发展和优化，只清理确认安全的垃圾文件。但建议：

1. 清理前查看清理项目，确认无误后再执行。
2. 重要数据定期备份。
3. 不熟悉的选项保持默认，不要随意勾选。
4. 系统优化功能中不熟悉的设置不要随意修改。
Dism++ 与 CCleaner、火绒等清理工具相比如何？
Dism++ 与这些工具定位不同，各有优势：

Dism++ 优势：深度清理 WinSxS 和 Windows 更新缓存（这是其他工具难以清理的），系统级底层操作，映像管理功能，完全免费开源无广告。

CCleaner 优势：应用软件缓存清理更全面，支持更多第三方软件。

火绒优势：集成安全防护功能，实时监控。

建议搭配使用：Dism++ 负责深度系统清理，其他工具负责日常维护。
Dism++ 与 WinDirStat、SpaceSniffer 等磁盘分析工具相比？
这两类工具功能不同：

Dism++：专注于系统清理和优化，清理 WinSxS、更新缓存等系统级垃圾。
WinDirStat/SpaceSniffer：磁盘空间可视化分析工具，帮助您找出哪些文件占用空间大。

建议先用 WinDirStat 分析磁盘占用，再用 Dism++ 清理系统垃圾，两者配合效果最佳。

其他问题

Dism++ 是微软官方出品的吗？
不是。Dism++ 是由国内个人开发者（初雨团队 Chuyu-Team）打造的免费、轻量、绿色、强大的 Windows 系统优化和垃圾清理工具。它并非微软官方出品，但其核心功能基于微软官方的 DISM（Deployment Image Servicing and Management）API 构建，并提供了远超系统自带 DISM 命令工具的图形化界面和更丰富的功能。
