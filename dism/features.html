功能介绍

Dism++ 集清理、优化、备份、驱动管理、镜像处理于一体，提供一站式系统维护方案。基于 CBS 底层 API，提供比原生 DISM 更强大的功能和更好的兼容性。

核心功能详解

运行 Dism++ 后，主界面分为左右两栏，左侧是功能列表，右侧是具体选项和信息

🧹 空间回收（核心清理功能）

Dism++ 最常用的功能。深度扫描并清理 Windows 系统中各类冗余文件，远超系统自带的磁盘清理工具。包括：

• Windows 更新清理：清理安装更新后留下的旧版本文件（C:\Windows\WinSxS\ 文件夹），这是释放大量 C 盘空间的关键。
• 系统临时文件：各种缓存、日志文件。
• DirectX 着色器缓存：游戏玩家清理此项有时能解决游戏异常。
• Windows Defender 防病毒：清理 Defender 的临时文件。
• 程序缓存：清理常见应用（如微信、QQ）的缓存文件。
• CompactOS：通过压缩系统文件来节省空间（可选功能）。
• NuGet 包缓存：v10.1.1002.2 新增清理规则。

实测可释放 10-30GB 空间。

🚀 启动项管理

可以非常方便地管理系统的启动项，直观展示所有开机自启程序与系统服务，支持一键禁用无用项。包括：

• 原生启动项：系统配置（msconfig）中的启动项。
• 计划任务：管理随计划任务启动的项目。
• 服务：管理和优化系统服务。
• Explorer shell 扩展：管理右键菜单的扩展项。

提供详细的系统服务列表及默认状态说明，帮助用户精准优化，降低系统资源占用，大幅提升系统启动速度。

📦 应用程序管理（Appx）

可以轻松卸载 Windows 10/11 预装的 Microsoft Store 应用（UWP 应用），即使是系统自带的"获取帮助"、"Mixed Reality"等通常无法卸载的应用，也能在这里强制移除。

支持批量卸载，有效清理系统预装软件冗余，让 Windows 更加干净清爽。

🔧 驱动管理

显示所有已安装的硬件驱动信息，支持批量备份、导出、卸载及安装新驱动。有效解决驱动冗余问题。

例如 NVIDIA 驱动历史版本可能占用数十 GB 空间，使用 Dism++ 可以一键清理旧版本驱动，释放大量硬盘空间。

支持驱动备份与恢复，重装系统后可快速还原所有驱动程序。

⚙️ 系统优化

通过勾选即可轻松修改大量系统隐藏设置，无需手动修改注册表。例如：

• 桌面体验：显示/隐藏快捷方式小箭头、任务栏时钟显示秒针等。
• 资源管理器：显示/隐藏文件扩展名、在任务栏显示所有图标等。
• 网络设置：优化 TCP/IP 连接数等。
• 安全设置：关闭 Windows Defender、关闭自动播放等。
• Win+X 菜单编辑：自定义 Win+X 快捷菜单。

将复杂的注册表修改封装为简单的勾选操作，让普通用户也能进行高级系统定制。

🔄 更新管理（ESD-ISO 转换）

可以离线添加或移除系统更新包（.cab 或 .msu 文件），还可以将官方的 ESD 格式镜像文件转换为 ISO 格式，方便制作系统安装盘。

支持扫描并选择性安装或卸载 Windows 更新补丁，还能将更新整合到系统镜像中。基于 GitHub 服务提供 wsuscan3.cab 的自动更新支持（v10.1.1002.1 新增）。

🛠️ 工具箱

包含一系列实用小工具：

• 系统备份/还原：使用 ESD 格式（压缩率高）对系统进行完整备份和还原。无需进入 PE，系统运行时即可完成。
• 春哥附体（God Mode）：一种特殊的崩溃保护模式，即使在系统资源极度匮乏的情况下，也能强行运行 Dism++ 进行修复。
• Hosts 编辑器：方便地编辑 Hosts 文件，支持只读修改（v10.1.1002.1 新增）。
• 文件浏览器：在系统预安装环境（PE）下非常有用。
• BCD 引导修复：修复引导故障。
• Imagex 工具：WIM 映像处理工具。
• ISO 生成器：将文件夹打包为 ISO 镜像。

💿 映像处理与 ISO 生成

完整支持 WIM/ESD 格式，提供创建、挂载、释放、互转功能。内置 ISO 生成器、Imagex 工具、引导修复及 BCD 启动菜单管理。

• 创建和编辑 WIM 映像
• 支持 ESD 格式转换
• 映像部署和安装
• 系统备份和恢复
• 解锁微软隐藏的 ESD 捕获、ESD 转 WIM 等高级功能

🛡️ 系统修复与安全加固

调用底层 CBS 服务执行 /RestoreHealth 命令修复损坏的系统文件，支持离线修复（PE 环境）。

提供 Hosts 文件编辑、右键菜单管理、预装应用卸载、系统精简等功能。支持关闭自动更新、修复引导故障，全面提升系统稳定性与安全性。

当系统出现文件损坏、启动问题时，使用系统修复功能检查文件完整性，自动修复损坏的系统文件，恢复系统正常运行。

工作原理

基于 CBS 底层 API，不依赖 DISM.exe

🔬 CBS 核心技术

Dism++ 直接使用 CBS（Component Based Servicing）核心 API，无需依赖原生 DISM 组件，具有更好的兼容性和稳定性。

CBS 是 Windows 的组件服务框架，负责管理系统组件、更新和功能启用/禁用。Dism++ 通过直接调用 CBS API，绕过 DISM.exe 命令行工具，实现更底层的系统操作与更快的响应速度。

🔓 解锁隐藏功能

微软在 DISM 中隐藏了一些高级功能，如 ESD 捕获、ESD 转 WIM 等。Dism++ 通过直接调用 CBS API，解锁这些隐藏功能，提供更多操作可能。

同时，Dism++ 还提供了大量 DISM 原本不支持的特性，如系统优化、启动项管理、Appx 管理等，使其成为一款功能全面的系统管理工具。

🌐 广泛系统兼容

支持从 Windows Vista 到 Windows 11 的所有版本，涵盖 x86、x64、ARM 等架构。一个工具解决不同系统版本的兼容性问题。

由于直接调用 CBS API，不依赖特定版本的 DISM.exe，因此能够在各种 Windows 版本上稳定运行，包括微软已停止支持的旧版本。

使用技巧

让 Dism++ 发挥最大效能的实用技巧

💡 定期清理 WinSxS

Windows 更新后，WinSxS 文件夹会积累大量旧版本组件文件。建议每月使用 Dism++ 的"空间回收"功能清理一次，通常可释放数 GB 空间。

💡 备份驱动后再清理

在使用驱动管理功能清理旧版本驱动前，建议先备份当前驱动。这样如果清理后出现问题，可以快速恢复。

💡 谨慎使用 CompactOS

CompactOS 通过压缩系统文件节省空间，但会增加 CPU 负担。SSD 硬盘空间充足的用户不建议开启，机械硬盘空间紧张的用户可以考虑。

💡 系统备份使用 ESD 格式

Dism++ 的系统备份使用 ESD 格式，压缩率高于 WIM，生成的备份文件更小。建议定期备份系统，以便出现问题时快速恢复。

💡 PE 环境下使用

Dism++ 可以在 PE 环境下运行，用于离线系统维护。将 Dism++ 加入 PE 启动盘，可在系统无法启动时进行修复。

💡 春哥附体模式

当系统资源极度匮乏、其他程序无法运行时，使用"春哥附体"模式可以强行运行 Dism++ 进行系统修复，是应急救场的利器。
