关于 Dism++

Dism++ 是一款由初雨团队采用微软内部 API 编写的开源免费实用工具，最初名为"Windows 更新清理工具"。基于 CBS 底层实现，不依赖 DISM.exe，提供完全的图形化操作界面。

项目背景

Dism++ 是一款由国内个人开发者（初雨团队 Chuyu-Team）打造的免费、轻量、绿色、强大的 Windows 系统优化和垃圾清理工具。它并非微软官方出品，但其核心功能基于微软官方的 DISM（Deployment Image Servicing and Management）API 构建，并提供了远超系统自带 DISM 命令工具的图形化界面和更丰富的功能。

项目最初名为"Windows 更新清理工具"，后发展为功能全面的系统管理工具，并更名为 Dism++。项目自 2011 年发布至今持续更新，已有 10 年以上的活跃开发历史。代码托管在 GitHub，由初雨团队与社区共同维护，规则库与语言包持续更新。

Dism++ 基于 CBS（Component Based Servicing）底层实现，不依赖 DISM.exe，提供完全的图形化操作界面，几乎支持 DISM 的所有功能以及大量 DISM 原本不支持的特性。它是一款轻量级系统管理工具，无需安装即可直接运行，兼容 Windows Vista/7/8/8.1/10/11 系统，涵盖 x86、x64、ARM 等架构。

您可以这样理解 Dism++

• 一个功能超级增强版的"磁盘清理"和"系统优化"工具。

• 一个图形化、用户友好版的 DISM 命令行工具。

• 一个集系统清理、维护、优化、修复于一身的"瑞士军刀"。

我们的使命

Dism++ 的使命是让每一位 Windows 用户都能轻松进行专业级的系统维护。我们将复杂的 DISM 命令和系统配置封装成简单的图形按钮和选项，让普通用户也能进行高级系统维护，如修复系统映像、安装更新包、管理驱动等。

我们相信，优秀的系统工具应该是免费、开源、绿色、无广告的。Dism++ 遵循 MIT 协议开源，代码公开透明，无任何隐藏费用或广告插件，完全由开发者用爱发电。
