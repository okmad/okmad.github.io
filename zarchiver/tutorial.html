ZArchiver 使用教程

安装、解压、压缩、乱码修复，新手一学就会

一、下载与安装

  1. 前往本站下载页，选择对应手机架构的 ZArchiver 安装包（主流手机选 arm64-v8a，免费无广告），通过网盘下载 APK 安装包。
  2. 首次安装时，安卓系统会提示「禁止安装未知来源应用」，在弹窗中选择允许当前浏览器 / 文件管理器安装应用即可（仅本次安装临时开启更安全）。
  3. 点击安装，完成后打开 ZArchiver，按提示授予文件访问权限（所有文件访问权限）。
  4. 建议首次使用先进入「设置」→「默认代码页」，选择 简体中文（GBK / GB2312），从根源上避免解压 Windows 压缩包时出现中文乱码。

二、如何解压压缩包（RAR / ZIP / 7Z）

  1. 打开 ZArchiver，软件会以文件管理器的形式展示手机存储目录。
  2. 浏览到压缩包所在位置（例如微信接收的文件一般在 Download 或 Android/data/com.tencent.mobileqq 目录）。
  3. 单击压缩包文件，在弹出菜单中选择：
  • 查看：不解压直接浏览压缩包内文件列表；
  • 解压到当前目录：解压到压缩包所在文件夹（最常用）；
  • 解压到 ./<压缩包名>/：自动新建同名文件夹存放，避免文件散乱（推荐）；
  • 解压到…：自选目标路径；
  • 解压到其他文件夹、测试压缩包（校验完整性）等。

如压缩包带密码，会弹出密码输入框，输入后点确定即可开始解压。

三、分卷压缩包怎么解压

常见分卷命名有 xxx.part1.rar / part2.rar、xxx.zip.001 / .002、xxx.7z.001 / .002 等。解压方法非常简单：

  • 确保所有分卷在同一文件夹且文件名完整；
  • 只需单击 第一个分卷（part1 / .001），选择「解压到…」，ZArchiver 会自动依次合并解压全部分卷；
  • 若提示缺少分卷，检查是否有分卷未下载完成或被手机管家误删。

四、如何压缩文件 / 创建压缩包

  1. 浏览并长按需要压缩的文件或文件夹；
  2. 在弹出菜单中选择「压缩」；
  3. 设置压缩格式（7Z / ZIP / TAR 等）、压缩等级、是否分卷、是否设置密码（ZIP / 7Z 支持）；
  4. 点击确定，等待压缩完成即可。

小技巧：需要手机间传输大量照片时，先压缩成单个 7Z 包再通过网盘发送，速度更快且不易丢文件。

五、解压中文乱码怎么解决

若解压 Windows 电脑打包的压缩包出现文件名乱码（如「娴嬭瘯鏂囦欢」）：

  1. 打开 ZArchiver →「设置」→「默认代码页」；
  2. 选择「简体中文（GBK / GB2312）」；
  3. 返回重新解压，文件名即可正常显示中文。

绝大多数中文乱码都是压缩包创建时的编码与解压端不一致导致，设置一次即可长期生效。

六、微信 / QQ 里收到的压缩包直接解压

  1. 在微信 / QQ 中点击压缩包文件 → 选择「用其他应用打开」；
  2. 选择「ZArchiver」；
  3. ZArchiver 会直接打开压缩包，选择解压路径即可完成解压，无需手动查找文件位置。

七、高级功能

  • 编辑压缩包内容：不解压即可删除、重命名压缩包内文件；
  • 查看压缩包信息：长按压缩包选择「信息」，查看格式、大小、压缩比等详情；
  • 设置默认解压路径：在设置中自定义默认解压目录，一键解压更省心；
  • 深色模式：支持明亮 / 深色主题切换，夜间使用更护眼；
  • 多选批量操作：长按文件进入多选模式，批量解压、压缩、删除文件，配合内置文件管理器高效整理手机存储。
