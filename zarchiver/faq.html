ZArchiver 常见问题解答

关于安卓解压软件 ZArchiver 的常见疑问，这里都有答案

ZArchiver 是免费的吗？有广告吗？

ZArchiver 完全免费、无广告、无需注册，且不申请联网权限，全部功能离线可用，本站提供的所有版本均可免费下载使用。

ZArchiver 支持哪些压缩格式？

解压支持：7z、zip、rar、rar5、tar、gzip、bzip2、xz、lzma、iso、cab、arj、lzh、lha、cpio、deb、rpm、dmg、msi、jar、apk、vhd、fat、ntfs、squashfs、chm、lz4、zstd 等30多种格式；创建支持：7z、zip、tar、gzip、bzip2、xz、lzma 等，其中 7z 与 zip 支持密码加密与分卷。

解压后文件名乱码怎么办？

打开 ZArchiver →「设置」→「默认代码页」，选择「简体中文（GBK / GB2312）」后重新解压即可。中文乱码通常是 Windows 压缩包的编码与手机端不一致导致，ZArchiver 的编码自动转换能力在同类软件中最强。

分卷压缩包（.001 / part1）怎么解压？

确保所有分卷位于同一文件夹，然后只需单击第一个分卷（如 xxx.7z.001 或 xxx.part1.rar）选择「解压到…」，ZArchiver 会自动识别并合并解压后续全部分卷，无需逐个操作。

无法访问 Android/data 或 Android/obb 文件夹？

这是 Android 11 及以上系统的安全限制，并非软件问题。可尝试：通过系统文件选择器授权访问；不同品牌（华为、小米、三星等）的授权入口不同；也可借助 Shizuku 等工具配合 ZArchiver 访问受限目录。

安装 APK 时提示「安装包解析失败」？

常见原因：① 下载不完整，建议重新下载并核对文件大小；② APK 文件版本与手机安卓版本不匹配，请下载适配机型的版本；③ 文件被安全软件误改后缀，确认文件为 .apk 格式。

ZArchiver 安全吗？会不会泄露隐私？

ZArchiver 无广告、无埋点、不申请联网权限，解压压缩全程在本地离线完成，不会上传任何文件数据，是安卓平台口碑与安全性俱佳的解压工具。建议从可信渠道下载安装包。

ZArchiver 和 RAR、7Zipper 哪个更好用？

ZArchiver 免费、无广告、体积小、格式全、中文兼容性最佳；RAR（WinRAR 安卓版）部分功能收费且含广告；7Zipper 广告较多。追求干净高效推荐 ZArchiver，追求品牌生态可选 RAR。

arm64、armv7、x86 版本怎么选？

主流近几年的手机选择 arm64-v8a（64位）即可；老旧机型（2015 年前或低端设备）选择 armeabi-v7a（32位）；安卓模拟器或 x86 架构设备选择 x86 版本。不确定时优先下载 arm64-v8a 版本，若安装失败再换其他架构。老系统设备可在历史版本合集中下载兼容旧版 Android 的旧版本。
