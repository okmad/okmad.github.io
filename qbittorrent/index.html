常见问题

解答您的疑惑

qBittorrent 安全吗？

完全安全！开源软件，代码公开可审查，无后门、无病毒。建议从官方渠道下载。

如何设置下载速度？

工具菜单 → 选项 → 速度，可以分别设置全局下载/上传限速，也可对单个任务限速。

支持磁力链接吗？

完全支持！复制磁力链接，点击"添加链接"即可自动解析下载。

如何开启 Web 远程控制？

工具 → 选项 → Web UI，勾选"启用 Web 用户界面"，设置用户名密码后即可访问。
