Linux 发行版安装命令

Linux 用户也可以通过包管理器直接安装：

Ubuntu / Debian

sudo apt update && sudo apt install qbittorrent

Fedora

sudo dnf install qbittorrent

Arch Linux

sudo pacman -S qbittorrent

openSUSE

sudo zypper install qbittorrent

安装帮助

Windows 安装

下载 .exe 安装包后双击运行，按照安装向导完成安装。安装时可选择简体中文界面。

macOS 安装

下载 .dmg 文件后打开，将 qBittorrent 拖拽到应用程序文件夹即可完成安装。

Linux 安装

AppImage 文件下载后赋予执行权限即可运行，或使用包管理器安装。
