qBittorrent 完全免费，没有任何广告、弹窗或捆绑软件。作为开源软件，代码完全透明，由全球开发者社区共同维护。您可以放心使用，不用担心隐私泄露或恶意软件。

  • 无广告、无弹窗、无捆绑
  • 开源代码，完全透明

高性能下载

基于 libtorrent-rasterbar 内核，qBittorrent 提供了卓越的下载性能。支持多种先进的 P2P 技术，确保您能够获得最快的下载速度。

  • 支持 DHT、PEX、LPD 协议
  • 支持 µTP 协议，优化带宽使用
  • 支持加密连接，防止 ISP 限速
  • 多线程下载，最大化利用带宽
  • 智能缓存管理，减少磁盘 I/O

磁力链接支持

直接支持磁力链接，无需先下载 .torrent 文件。复制磁力链接后，qBittorrent 会自动识别并开始下载，让您的下载体验更加便捷。

  • 自动识别剪贴板中的磁力链接
  • 支持多种磁力链接格式
  • 快速获取元数据
  • 支持拖放操作

内置搜索引擎

集成主流 BT 搜索引擎，无需打开浏览器即可搜索资源。支持多站点同时搜索，快速找到您需要的内容。

  • 集成多个主流 BT 搜索站点
  • 支持多站点同时搜索
  • 搜索结果直接添加下载
  • 支持自定义搜索引擎插件

RSS 订阅器

内置 RSS 订阅功能，可以自动订阅种子源并定时检查更新。非常适合追番、追剧的用户，新资源发布后自动下载。

  • 自动检查 RSS 更新
  • 支持关键词过滤
  • 智能下载规则
  • 支持正则表达式匹配

Web 远程控制

通过浏览器远程管理下载任务，支持手机、平板、电脑跨平台控制。无论您身在何处，都可以管理家中的下载任务。

  • 响应式 Web 界面
  • 支持 HTTPS 加密连接
  • 用户认证保护
  • 支持移动设备访问

高级设置

丰富的选项让您完全控制下载行为，从带宽限速到连接数限制，从代理设置到 IP 过滤，满足各种高级需求。

  • 带宽限速（全局/单个任务）
  • 连接数限制
  • 支持 SOCKS5/HTTP 代理
  • IP 过滤规则
  • 端口映射设置
  • 队列管理

智能文件选择

下载前可预览种子内文件列表，选择性下载需要的部分，节省时间和空间。支持按文件大小、类型筛选，设置优先级。

  • 预览种子文件列表
  • 选择性下载文件

  • 边下边播支持

跨平台支持

支持 Windows、macOS、Linux、FreeBSD 等主流操作系统，让您在不同设备上都能获得一致的使用体验。

安全与隐私

支持多种安全特性，保护您的隐私。从连接加密到 IP 黑名单，从匿名模式到代理支持，全方位保护您的下载安全。
