常见问题

解答您的疑惑

qBittorrent 安全吗？是否有后门？

完全安全！qBittorrent 是完全开源的软件（GPLv2 协议），代码托管在 GitHub 上，全球开发者都可以审查代码。没有任何后门、间谍软件或恶意代码。长期被安全社区推荐，是值得信赖的开源软件。

建议：请从官方网站或可信渠道下载，避免从不明来源下载可能被篡改的版本。

下载速度很慢怎么办？

下载速度慢可能有多种原因，请按以下步骤排查：

  1. 检查种子健康度：确保种子有足够的做种者（Seeders）
  2. 检查端口映射：确保防火墙/路由器已正确映射端口（默认 6881 或自定义端口）
  3. 启用 UPnP：在"工具 → 选项 → 连接"中启用 UPnP
  4. 增加连接数：适当增加全局最大连接数（建议 500-1000）
  5. 使用增强版：增强版内置了优化的 Tracker 列表，可以提升连接效率
  6. 启用 DHT/PEX：确保在"工具 → 选项 → BitTorrent"中启用了 DHT 和 PEX

如何设置中文界面？

设置中文界面的方法：

  1. 安装时选择：Windows 安装程序在安装过程中可以选择"简体中文"
  2. 已安装后更改：
    • 打开 qBittorrent
    • 点击菜单 "Tools" → "Options"（或按 Ctrl+Alt+S）
    • 在左侧选择 "Behavior"
    • 在 "Interface" 区域找到 "Language"
    • 从下拉菜单中选择 "简体中文"
    • 点击 "Apply" 然后 "OK"
    • 重启 qBittorrent 生效

是否支持下载百度网盘/迅雷链接？

不支持。qBittorrent 仅支持以下协议：

  • BitTorrent 协议：.torrent 种子文件
  • 磁力链接：magnet:?xt=... 格式的链接

不支持以下协议：

  • 百度网盘链接
  • 迅雷专用链接（thunder://）
  • 电驴链接（ed2k://）
  • HTTP/FTP 直接下载

如需下载这些类型的资源，请使用相应的专用工具。

如何设置下载速度限制？

设置速度限制的方法：

  1. 全局速度限制：
    • 点击"工具" → "选项" → "速度"
    • 设置全局上传和下载速度上限
  2. 快速切换：
    • 点击工具栏上的"替代速度限制"按钮（乌龟图标）
    • 或按快捷键 Ctrl+Shift+Alt+S
  3. 单个任务限制：
    • 右键点击任务
    • 选择"限制上传速度"或"限制下载速度"
    • 输入限制值（单位：KB/s）

支持磁力链接吗？

完全支持！使用方法：

  1. 复制磁力链接（magnet:?xt=... 格式）
  2. qBittorrent 会自动识别剪贴板内容并弹出添加窗口
  3. 或者手动点击"文件" → "添加链接"
  4. 粘贴磁力链接
  5. 点击"确定"开始下载

提示：磁力链接会先获取元数据，可能需要几秒到几分钟时间。

如何开启 Web 远程控制？

启用 Web UI 的步骤：

  1. 打开"工具" → "选项" → "Web UI"
  2. 勾选"Web 用户界面"
  3. 设置监听端口（默认 8080）
  4. 设置用户名和密码（必须设置强密码！）
  5. 可选：启用 HTTPS 增强安全性
  6. 点击"应用"保存设置

访问方式：

  • 本机访问：http://localhost:8080
  • 局域网访问：http://本机IP:8080
  • 外网访问：需要配置路由器端口映射

安全提示：请务必设置强密码，避免被他人非法访问。

Windows 安装时提示缺少 DLL 文件？

这通常是因为缺少 Visual C++ 运行库。解决方法：

  1. 下载并安装 Visual C++ Redistributable
  2. 如果使用 32 位系统，下载 x86 版本
  3. 安装完成后重启电脑
  4. 再次尝试安装 qBittorrent

如果问题仍然存在，请尝试使用便携版（绿色版）。

增强版和普通版有什么区别？

增强版在官方原版基础上增加了以下功能：

  • 优化的下载引擎：提升下载速度和稳定性
  • 内置 Tracker 列表：自动更新优质 Tracker，提升连接效率
  • 自动屏蔽吸血客户端：保护上传资源
  • IP 过滤规则：内置恶意 IP 屏蔽列表
  • 界面优化：支持更多主题和自定义选项

普通版保持官方原版的简洁体验，适合喜欢原汁原味的用户。

推荐：普通用户建议使用增强版，可以获得更好的下载体验。

如何选择性下载文件？

选择性下载文件的方法：

  1. 添加种子时，在弹出的窗口中切换到"内容"标签
  2. 可以看到种子中包含的所有文件列表
  3. 勾选需要下载的文件，取消不需要的文件
  4. 可以设置单个文件的下载优先级（高/正常/低/不下载）
  5. 点击"确定"开始下载

提示：已添加的任务也可以右键选择"优先级"来调整文件下载顺序。

macOS 提示"无法打开，因为它来自身份不明的开发者"？

这是 macOS 的安全机制，解决方法：

  1. 打开"系统偏好设置" → "安全性与隐私"
  2. 在"通用"标签下，点击"仍要打开"
  3. 或者在应用程序文件夹中，右键点击 qBittorrent，选择"打开"
  4. 在弹出的对话框中点击"打开"

或者使用命令行：

sudo xattr -r -d com.apple.quarantine /Applications/qbittorrent.app
