安装指南

1

下载安装包

访问下载页面，选择适合您操作系统的版本。建议下载增强版以获得更好的体验。

提示：Windows用户可以选择安装版或绿色便携版。便携版无需安装，解压即可使用。
2

Windows 安装

  1. 双击下载的 .exe 文件启动安装程序
  2. 选择安装语言（建议选择简体中文）
  3. 阅读并同意许可协议
  4. 选择安装路径（建议使用默认路径）
  5. 选择要创建的快捷方式
  6. 点击"安装"按钮开始安装
  7. 安装完成后，勾选"启动 qBittorrent"并点击"完成"
3

macOS 安装

  1. 打开下载的 .dmg 文件
  2. 将 qBittorrent 图标拖拽到"应用程序"文件夹
  3. 在"应用程序"文件夹中找到 qBittorrent 并双击启动
  4. 首次启动可能需要在"系统偏好设置 → 安全性与隐私"中允许运行
4

Linux 安装

Linux 用户有多种安装方式：

# Ubuntu/Debian sudo apt-get update && sudo apt-get install qbittorrent # Fedora sudo dnf install qbittorrent # Arch Linux sudo pacman -S qbittorrent

或者下载 AppImage 文件，赋予执行权限后直接运行：

chmod +x qbittorrent-*.AppImage ./qbittorrent-*.AppImage

基础使用

1

添加下载任务

qBittorrent 支持多种方式添加下载任务：

  • 种子文件：点击"文件" → "添加种子文件"，或直接拖拽 .torrent 文件到窗口
  • 磁力链接：点击"文件" → "添加链接"，粘贴磁力链接（magnet:?xt=...）
  • 批量添加：支持一次添加多个种子文件
小技巧：复制磁力链接后，qBittorrent 会自动识别并弹出添加窗口。
2

管理下载任务

在任务列表中，您可以：

  • 暂停/恢复：右键点击任务，选择"暂停"或"恢复"
  • 设置优先级：右键 → "优先级"，选择高、最高、低、最低
  • 限制速度：右键 → "限制上传速度/下载速度"
  • 删除任务：右键 → "删除"，可选择是否同时删除文件
  • 打开文件夹：右键 → "打开目标文件夹"
3

文件选择

添加种子后，可以选择性下载部分文件：

  1. 添加种子时，在弹出的窗口中切换到"内容"标签
  2. 勾选需要下载的文件，取消不需要的文件
  3. 可以设置单个文件的下载优先级
  4. 点击"确定"开始下载
4

搜索功能

增强版内置了搜索功能：

  1. 点击"查看" → "搜索引擎"打开搜索面板
  2. 在搜索框中输入关键词
  3. 选择要使用的搜索引擎
  4. 点击搜索按钮
  5. 双击搜索结果即可添加下载

高级设置

1

速度限制

在"工具" → "选项" → "速度"中可以设置：

  • 全局速度限制：设置全局上传/下载速度上限
  • 替代速度限制：快速启用/禁用速度限制
  • 计划任务：在特定时间段自动启用速度限制
2

连接设置

在"工具" → "选项" → "连接"中可以配置：

  • 监听端口：默认为随机端口，建议设置为固定端口（如 51413）
  • UPnP：启用 UPnP 可自动配置路由器端口映射
  • 最大连接数：根据网络情况调整，一般设置为 500-1000
  • 代理设置：支持 SOCKS5 和 HTTP 代理
3

Web UI 远程控制

启用 Web UI 可以通过浏览器远程管理：

  1. 打开"工具" → "选项" → "Web UI"
  2. 勾选"Web 用户界面"
  3. 设置监听端口（默认 8080）
  4. 设置用户名和密码
  5. 点击"应用"保存设置
  6. 在浏览器中访问 http://本机IP:8080
注意：请设置强密码，并考虑启用 HTTPS 加密连接。
4

RSS 订阅

使用 RSS 订阅可以自动下载更新的资源：

  1. 点击"查看" → "RSS 阅读器"
  2. 点击"新建订阅"，输入 RSS 地址
  3. 右键订阅 → "编辑 RSS 订阅"
  4. 设置下载规则（如关键词过滤）
  5. 启用自动下载
5

IP 过滤

启用 IP 过滤可以屏蔽恶意 IP：

  1. 打开"工具" → "选项" → "连接"
  2. 勾选"启用 IP 过滤"
  3. 下载 IP 过滤规则文件（如 level1.bin）
  4. 指定过滤文件路径
  5. 点击"应用"生效

使用技巧

提升下载速度

  • 确保端口映射正确（启用 UPnP 或手动映射）
  • 适当增加最大连接数
  • 启用 DHT、PEX、LPD
  • 选择健康度高的种子
  • 使用增强版的内置 Tracker 列表

节省磁盘空间

  • 选择性下载文件
  • 设置下载完成后自动移动文件
  • 定期清理已完成的任务
  • 启用磁盘缓存减少写入次数

保护隐私安全

  • 启用加密连接
  • 使用 IP 过滤规则
  • 考虑使用 VPN 或代理
  • 定期更新软件版本

快捷键

  • Ctrl+N - 添加种子文件
  • Ctrl+Shift+N - 添加链接
  • Ctrl+P - 暂停所有
  • Ctrl+R - 恢复所有
  • Del - 删除选中任务
