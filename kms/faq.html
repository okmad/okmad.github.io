下载与安全

HEU KMS Activator 是否完全免费？
是的，HEU KMS Activator 是完全免费的软件，由开发者"知彼而知己"用爱发电长期维护。可免费下载、使用，无任何隐藏费用。软件不包含广告、不捆绑第三方软件、无后门，界面简洁清爽。
为什么杀毒软件会报毒？工具真的有毒吗？
工具本身无毒。激活工具修改系统授权状态的工作机制与病毒行为类似，触发了杀软（包括 Windows Defender）的启发式检测，因此会被误报为 HackTool/威胁。这不是工具真的有毒。

解决方法：下载前先临时关闭 Windows Defender 实时防护，或将工具所在文件夹添加到 Defender 的排除列表中。激活完成后可重新开启防护。如果仍然不放心，可以选择不下载，改用 MAK 密钥手动激活。
支持哪些 Windows 和 Office 版本？
覆盖范围极广，几乎通吃：

Windows 系统：XP、Vista、7、8、8.1、10、11 全版本，含 LTSC 长期服务版与评估版。
Windows Server：Server 2008 / 2012 / 2016 / 2019 / 2022 / 2025。
Office 套件：Office 2010 / 2013 / 2016 / 2019 / 2021 / 2024，Microsoft 365。
架构：x86、x64、ARM64（v63.2 起适配 ARM64 Win11 的 KMS 激活）。
需要联网才能激活吗？
不需要。HEU 自带微型 KMS 服务器模拟器，支持完全离线激活，断网环境同样有效，特别适合装机后的离线环境。

需要注意的是：数字许可证（HWID）激活需要联网，而 TSForge、KMS38、KMS、OEM 等方式均可离线完成。智能激活模式下，工具会根据联网状态自动选择合适方案。
需要安装吗？怎么运行？
不需要安装，绿色便携。下载 ISO 镜像后用 7-Zip 解压或挂载到虚拟光驱，右键点击 HEU_KMS_Activator.exe，选择"以管理员身份运行"即可。约 4.5MB 单文件，不会写入系统注册表，卸载只需删除文件夹。

激活使用

怎么用 HEU 激活 Windows？
三步即可，全程不超过 3 分钟：

1. 关闭杀软，解压运行：右键以管理员身份运行 HEU_KMS_Activator.exe。
2. 选择智能激活：默认即"智能激活"模式，确认勾选"智能识别最佳激活方式"，点击"开始"。
3. 等待完成：进度条到 100% 后弹出"激活成功"提示，重启系统即可。

工具会自动检测系统版本、联网状态与已安装的 Office，智能匹配最优激活方案，无需手动选择。
怎么单独激活 Office？
在主界面右上角切换到"Office 激活"标签页，操作流程与 Windows 激活一致。工具会自动将零售版 Office 转换为批量授权版（VL），然后完成激活，过程约 3 秒，完成后重新打开 Word 即可。

对于 Office 2016 及以上版本，TSForge 是首选；对于 Office 365 等不支持 TSForge 的版本，会自动切换为 Ohook（劫持 Office）。两者都能实现永久激活效果。
TSForge 和数字许可证哪个更好？
两者都是永久激活，效果相同。区别在于：

数字许可证：需联网，是"微软层面的真实激活"，仅支持 Win10/11 零售版渠道。
TSForge：不需要联网，覆盖范围更广，几乎所有 Windows/Office 版本都支持。

如果条件允许（能联网且版本支持），优先选择数字许可证；如果无法联网或版本不支持，TSForge 是完美替代方案。
激活失败，提示 0x80080005 或 0xC004F074 怎么办？
绝大多数情况是杀毒软件拦截导致的。请按以下步骤处理：

1. 临时关闭 Windows Defender 实时防护或第三方杀软（360、火绒、腾讯管家等）。
2. 将工具目录加入杀软排除列表后重试。
3. 确认已以管理员身份运行。
4. 若仍失败，使用工具中的"清除 KMS 客户端信息"功能后再激活。
5. 也可切换为"KMS38"或"数字权利"模式重试。
支持 Windows 家庭版（Home）吗？
支持。HEU 支持 Windows 10/11 的全版本，包括家庭版、专业版、教育版、企业版、LTSC 长期服务版等。不过数字许可证激活对某些版本（如 LTSC）不适用，工具会自动切换为 TSForge 或 KMS38 方案。
工具提示"已永久激活"，但设置里还是显示未激活？
大概率是系统界面没有刷新。重启电脑后再查看即可。如果重启后仍然显示未激活，使用命令行确认真实状态——按 Win+R 输入 slmgr.vbs -xpr，命令行返回的结果是最准确的。若显示"该计算机已永久激活"或"激活至 2038 年"，即为成功。

进阶与维护

激活后能正常收到系统更新吗？
可以。HEU 的激活方式（数字许可证、TSForge、KMS38）不会影响 Windows Update 的正常运作，系统可以正常接收微软推送的安全更新和功能更新，可放心升级 22H2 及后续版本。这也是它与某些"阉割版"激活方案的本质区别。
怎么确认已经激活成功？
两种方法：

方法一（最准确）：按 Win+R 打开运行，输入 slmgr.vbs -xpr 回车，稍后弹出窗口显示激活到期时间。若显示"该计算机已永久激活"或"激活至 2038 年"，即成功。

方法二：打开设置 → 系统 → 激活，在"激活状态"栏查看。若显示"Windows 已激活"或"Windows 已使用数字许可证激活"即为成功。
Windows 7 用这个工具有什么注意事项？
HEU 在 Windows 7 上无需依赖 .NET Framework，开箱即用。对于 Windows 7 旗舰版等不支持数字激活的版本，工具优先使用 TSForge 实现永久激活。Windows 7 专业版/企业版还可以选择 OEM 激活方式（6 种模式可选）。
怎么用静默参数批量激活？
通过命令行参数可实现无人值守激活，适合系统封装与批量部署。最常用命令：

HEU_KMS_Activator.exe /kwi /dig /nologo

含义：以静默方式使用数字许可证永久激活 Windows，不显示界面。如需同时激活 Office，加上 /kof 参数。

常用参数：/s 静默 · /dig 数字许可证 · /kms38 KMS38 · /oem OEM · /kof Office · /kwi Windows · /nologo 无界面。
重装系统后需要重新激活吗？
视激活方式而定：

数字许可证：绑定主板，重装同版本系统可自动联网激活，无需再次运行工具。
其他方式：需重新激活。建议重装前使用工具的"备份"功能导出激活证书、密钥、SKU 信息，重装后点击"还原"即可恢复激活状态。
