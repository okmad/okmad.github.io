安装与语言设置

步骤1：下载安装包

访问下载页面，选择适合您操作系统的版本：

  • Windows用户：推荐下载64位安装版
  • macOS用户：根据芯片类型选择Apple Silicon或Intel版本
  • Linux用户：可选择DEB、RPM或Flatpak包

步骤2：安装程序

Windows系统：

  1. 双击下载的.exe文件
  2. 如果出现"Windows已保护你的电脑"提示，点击"更多信息"→"仍要运行"
  3. 按照安装向导完成安装
  4. 可选择文件关联和右键菜单选项

macOS系统：

  1. 双击.dmg文件打开
  2. 将PeaZip拖入Applications文件夹
  3. 首次运行需在终端执行：xattr -dr com.apple.quarantine /Applications/peazip.app

步骤3：设置中文界面

PeaZip支持30多种语言，设置中文界面的方法：

  1. 启动PeaZip
  2. 点击菜单栏的 Options → Settings
  3. 切换到 Localization 标签
  4. 在语言列表中选择 chs.txt（简体中文）
  5. 点击 OK 保存设置

重启程序后界面将变为中文。

如何压缩文件

方法一：使用右键菜单（推荐）

  1. 在文件资源管理器中选中要压缩的文件或文件夹
  2. 右键点击，选择 PeaZip → 添加到压缩文件
  3. 在弹出的窗口中设置压缩选项
  4. 点击 确定 开始压缩

方法二：使用PeaZip主界面

  1. 启动PeaZip
  2. 浏览并选中要压缩的文件
  3. 点击工具栏的 添加 按钮（或按 Ctrl+N）
  4. 在压缩设置窗口中配置选项
  5. 点击 确定 开始压缩

压缩选项说明

  • 格式：推荐使用7Z（高压缩率）或ZIP（兼容性好）
  • 压缩级别：
    • 存储：不压缩，仅打包
    • 快速：压缩速度快，压缩率较低
    • 标准：平衡速度和压缩率
    • 最大：压缩率高，速度较慢
    • 极限：最高压缩率，速度最慢
  • 字典大小：越大压缩率越高，但占用内存更多

如何解压文件

方法一：使用右键菜单

  1. 右键点击压缩包文件
  2. 选择 PeaZip 菜单
  3. 选择解压选项：
    • 解压到当前文件夹：快速解压到同一目录
    • 解压到...：自定义解压路径
    • 解压到 [文件夹名]：创建同名文件夹并解压

方法二：使用PeaZip主界面

  1. 双击压缩包在PeaZip中打开
  2. 浏览压缩包内容，选择要解压的文件
  3. 点击工具栏的 解压 按钮（或按 Ctrl+E）
  4. 选择解压路径和选项
  5. 点击 确定 开始解压

解压加密文件

如果压缩包有密码保护：

  1. 解压时会弹出密码输入框
  2. 输入正确密码后点击 确定
  3. 如果密码正确，文件将正常解压

如何加密压缩

设置密码加密

  1. 在压缩设置窗口中，点击 加密 选项卡
  2. 输入密码并确认
  3. 选择加密算法：
    • AES-256：推荐，安全且速度快
    • Twofish：高安全性加密算法
    • Serpent：最高安全性，速度较慢
  4. 勾选 加密文件名 可隐藏文件列表
  5. 点击 确定 开始压缩

使用双重认证（高级）

PeaZip支持密码+密钥文件的双重认证：

  1. 准备一个密钥文件（任意文件，如图片、文档等）
  2. 在加密设置中勾选 使用密钥文件
  3. 选择或创建密钥文件
  4. 设置密码
  5. 解压时需要同时提供密码和密钥文件

⚠️ 重要提示：请妥善保管密钥文件，丢失后将无法解压文件！

如何分卷压缩

创建分卷压缩包

  1. 在压缩设置窗口中，找到 分卷 选项
  2. 设置分卷大小：
    • 可选择预设大小（如100MB、700MB等）
    • 或自定义大小（如10M、1G等）
  3. 设置其他压缩选项
  4. 点击 确定 开始压缩

解压分卷文件

解压分卷压缩包时：

  • 确保所有分卷文件在同一目录下
  • 只需打开第一个分卷文件（通常为.001或.part1.rar）
  • PeaZip会自动识别并合并所有分卷
  • 按正常流程解压即可

如何转换格式

转换压缩包格式

  1. 在PeaZip中打开要转换的压缩包
  2. 点击菜单 转换 → 转换压缩包
  3. 选择目标格式（如从ZIP转为7Z）
  4. 设置压缩选项
  5. 选择输出路径
  6. 点击 确定 开始转换

批量转换

  1. 选中多个压缩包文件
  2. 右键选择 转换
  3. 设置统一的转换选项
  4. 点击 确定 批量转换

使用技巧

💡 提高压缩率

  • 使用7Z格式而非ZIP
  • 选择"最大"或"极限"压缩级别
  • 增加字典大小（需要更多内存）
  • 启用固实压缩

⚡ 提高压缩速度

  • 选择"快速"压缩级别
  • 启用多线程压缩
  • 使用较小的字典大小
  • 禁用固实压缩

🔒 增强安全性

  • 使用AES-256加密
  • 启用双重认证（密码+密钥文件）
  • 加密文件名以隐藏文件列表
  • 使用强密码（混合字符、数字、符号）

📂 文件管理技巧

  • 使用标签页同时管理多个位置
  • 设置书签快速访问常用文件夹
  • 使用搜索功能快速定位文件
  • 利用过滤功能显示特定类型文件
