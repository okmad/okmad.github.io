更轻的 Windows 播放中心

PotPlayer 是 Daum 体系下发展起来的 Windows 多媒体播放器，支持 DXVA、CUDA、QuickSync 等硬件加速，以最少的资源制造最华丽的表现。内置强大解码器，无需额外插件即可播放几乎所有音视频格式。

核心优势

🎬

格式覆盖广

支持 500+ 种音视频格式，包括 MP4、MKV、AVI、MOV、FLV 等主流格式，以及 4K/8K 超高清和 HDR 内容，无需额外安装解码器。

⚡

硬件加速

支持 DXVA、CUDA、QuickSync 等硬件加速路径，在合适硬件上可以降低 CPU 占用，改善高清视频播放体验。

📝

字幕控制细

支持 SMI、SRT、VobSub、蓝光字幕以及 ASS/SSA 动画字幕，适合课程、影视、外语学习等多字幕场景。

🚫

完全无广告

软件完全无广告，提供纯净的播放体验，专注于视频播放功能，无任何干扰。

🎨

界面自定义

支持丰富的皮肤主题，可自定义界面颜色和布局，打造专属播放器外观。

🔧

OpenCodec 支持

使用时，无需再麻烦地安装各种全能编解码器，支持 OpenCodec，用户自定义添加需要的编解码器。
