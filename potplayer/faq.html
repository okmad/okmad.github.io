常见问题

下载和安装过程中遇到问题？查看以下常见问题解答

下载与安装

PotPlayer 是完全免费的吗？ ▼
是的，PotPlayer 对个人用户完全免费，无任何功能限制。我们提供纯净无广告的版本，您可以放心使用。软件完全无广告，专注于视频播放功能。
下载后无法安装怎么办？ ▼
请确保您的系统版本满足最低要求。Windows 用户请以管理员身份运行安装程序。如仍遇到问题，请尝试关闭杀毒软件后重新安装。建议从官方网站下载，避免使用第三方下载站提供的修改版本。
应该选择 64 位还是 32 位版本？ ▼
现代 Windows 设备通常使用 64 位。仅在插件或旧环境需要时选择 32 位。您可以右键"此电脑" → 属性，查看"系统类型"。如果显示"64 位操作系统"，建议选择 64 位版本。
如何更新到最新版本？ ▼
PotPlayer 会在启动时自动检查更新。您也可以手动访问本网站下载最新版本。建议定期更新以获取最新功能和安全修复。在设置中可以配置自动更新选项。

播放问题

支持哪些视频格式？ ▼
PotPlayer 支持 500+ 种音视频格式，包括 MP4、MKV、AVI、MOV、FLV 等主流格式，以及 4K/8K 超高清和 HDR 内容，无需额外安装解码器。支持 OpenCodec，用户自定义添加需要的编解码器。
播放视频时卡顿怎么办？ ▼
1. 启用硬件加速：在设置中启用 DXVA、CUDA 或 QuickSync 硬件加速
2. 降低视频质量：调整视频渲染设置
3. 关闭不必要的后台程序
4. 更新显卡驱动程序
5. 检查系统资源占用情况
如何启用硬件加速？ ▼
打开 PotPlayer，按 F5 打开设置，选择"解码器"选项卡，勾选"使用硬件加速"。支持 DXVA、CUDA、QuickSync 等硬件加速路径，可以降低 CPU 占用，改善高清视频播放体验。
某些格式无法播放怎么办？ ▼
PotPlayer 内置强大解码器，支持大多数格式。如遇到特殊格式无法播放，可以尝试：
1. 更新 PotPlayer 到最新版本
2. 安装 OpenCodec 扩展编解码器
3. 手动添加需要的编解码器
4. 检查文件是否损坏

字幕问题

字幕显示乱码怎么办？ ▼
字幕乱码通常是由于编码问题导致的。解决方法：
1. 右键点击字幕，选择"字幕编码"，尝试不同的编码方式
2. 常见编码：UTF-8、GBK、GB2312
3. 使用文本编辑器打开字幕文件，另存为 UTF-8 编码
4. 下载其他版本的字幕文件
如何加载外挂字幕？ ▼
1. 点击菜单「字幕」→「加载字幕」，选择字幕文件
2. 直接将字幕文件拖拽到播放窗口
3. 将字幕文件与视频文件放在同一目录，文件名相同，PotPlayer 会自动加载
支持 SRT、ASS、SSA、SMI、VobSub 等多种字幕格式
字幕不同步怎么办？ ▼
1. 使用快捷键 Alt+左/右方向键调整字幕延迟
2. 右键点击字幕，选择"字幕同步"
3. 手动输入延迟时间（正数为延迟，负数为提前）
4. 下载其他版本的字幕文件
如何调整字幕大小和样式？ ▼
1. 右键点击字幕，选择"字幕字体"
2. 调整字体大小、颜色、样式
3. 在设置中可以配置默认字幕样式
4. 对于 ASS/SSA 字幕，样式由字幕文件决定，可在字幕设置中覆盖

其他问题

如何设置 PotPlayer 为默认播放器？ ▼
1. 打开 PotPlayer，按 F5 打开设置
2. 选择"关联"选项卡
3. 勾选需要关联的文件类型
4. 点击"应用到系统"
或者在 Windows 设置中，选择"应用"→"默认应用"，找到 PotPlayer 并设置为默认。
如何截图？ ▼
1. 快捷键 Ctrl+S：保存当前画面
2. 快捷键 Ctrl+E：高级截图
3. 右键菜单"视频"→"截图"
可在设置中配置截图格式（PNG、JPG、BMP）和保存路径。
如何录制视频？ ▼
1. 右键菜单"音频"→"音频录制"或"视频"→"视频录制"
2. 设置录制参数（格式、质量、保存路径）
3. 点击开始录制
注意：仅支持录制正在播放的内容，请遵守版权法规。
PotPlayer 支持 Windows 7 吗？ ▼
是的，PotPlayer 支持 Windows 7 及以上版本的 Windows 操作系统，包括 Windows 7、8、8.1、10 和 11。对于 Windows 7 用户，建议安装最新的系统更新和显卡驱动以获得最佳体验。
