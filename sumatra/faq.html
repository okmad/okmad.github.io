常见问题

这里有您可能遇到的问题和解答

安装与下载

SumatraPDF 完全免费吗？
是的！SumatraPDF 是完全免费的开源软件，基于 GPLv3 协议。无广告、无内购、无付费版本，所有功能均可免费使用。代码托管在 GitHub，欢迎查看与贡献。
安装版和便携版有什么区别？
安装版会注册到系统，自动关联 PDF 等文件格式，配置保存在用户目录。便携版无需安装，解压即用，不写入注册表，配置保存在程序目录，适合 U 盘携带或在多台电脑间切换使用。
SumatraPDF 支持哪些操作系统？
SumatraPDF 仅支持 Windows 平台，包括 Windows 7、8、10、11，提供 32 位、64 位和 ARM64 版本。不支持 macOS 和 Linux。Mac/Linux 用户可考虑其他替代工具。
如何将 SumatraPDF 设为默认 PDF 阅读器？
方法一：右键点击任意 PDF 文件 → "打开方式" → "选择其他应用" → 选择 SumatraPDF → 勾选"始终使用此应用打开 .pdf 文件"。

方法二：在 Windows 设置 → 应用 → 默认应用中，找到 SumatraPDF 并设置为 PDF 的默认打开程序。

方法三：在 SumatraPDF 中，点击菜单 → 设置 → 选项 → 在"默认阅读器"部分点击"设为默认 PDF 阅读器"。

使用与功能

SumatraPDF 支持哪些文件格式？
SumatraPDF 支持 PDF、EPUB、MOBI、CBZ、CBR、DjVu、XPS、CHM、FB2、PDB、TIFF 以及常见图片格式（JPG、PNG 等），一软件满足您所有阅读需求。
如何使用全文搜索？
按 Ctrl+F 打开搜索栏，输入关键词后回车。搜索结果会高亮显示，可使用 F3 或 Enter 键跳转到下一个匹配项，Shift+F3 跳转到上一个。支持正则表达式搜索。
如何添加书签？
打开文档后，按 Ctrl+Shift+B 或点击菜单 → 书签 → 添加书签，即可为当前页面添加书签。书签保存在侧边栏的书签列表中，点击可快速跳转。
如何使用演示模式？
按 F12 键进入演示模式（幻灯片模式），页面会全屏显示。可使用方向键或空格键翻页，按 Esc 退出演示模式。适合教学和会议演示场景。
如何自定义快捷键？div>
打开菜单 → 设置 → 高级选项，会打开配置文件 SumatraPDF-settings.txt。在文件中找到 [KeyboardShortcuts] 部分，按格式修改快捷键。修改后保存并重启 SumatraPDF 生效。
如何切换深色模式？
打开菜单 → 设置 → 主题颜色，可选择预设主题或自定义颜色。也可在配置文件中设置 PreferredBackgroundColor 和 TextColor 实现深色背景阅读。

反向同步与 LaTeX

什么是反向同步（Inverse Search）？
反向同步是指在 PDF 阅读器中双击某处，自动跳转到 LaTeX 源代码中对应的行。这对编写论文、技术文档的 LaTeX 用户非常有用，可大幅提升编写效率。
如何配置反向同步？
打开菜单 → 设置 → 选项 → 反向搜索，设置 LaTeX 编辑器的路径和命令行参数。例如对于 TeXworks："C:\Program Files\TeXworks\TeXworks.exe" "%f" -line=%l。配置完成后，双击 PDF 即可跳转到源码。
支持哪些 LaTeX 编辑器？
支持所有可通过命令行调用的编辑器，包括 TeXworks、VS Code、TeXstudio、Notepad++、Sublime Text 等。只需配置正确的命令行参数即可。

其他问题

SumatraPDF 会收集用户数据吗？
不会。SumatraPDF 是完全开源的软件，不收集、不上传任何用户数据。所有操作都在本地完成，不发送任何遥测信息，保护你的隐私。
如何备份配置？
安装版的配置文件保存在 %APPDATA%\SumatraPDF\SumatraPDF-settings.txt，复制该文件即可备份。便携版的配置保存在程序目录下，直接复制整个文件夹即可。
为什么有些 PDF 无法打开？
可能原因：1) PDF 文件已损坏；2) PDF 使用了特殊加密；3) PDF 使用了不支持的特性。建议尝试更新到最新版本，或使用其他阅读器打开验证文件是否正常。
如何参与 SumatraPDF 开发或反馈问题？
SumatraPDF 是开源项目，欢迎在 GitHub 上提交 Issue 反馈问题或建议，也欢迎提交 Pull Request 贡献代码。访问 github.com/sumatrapdfreader/sumatrapdf 参与开发。
SumatraPDF 有手机版吗？
目前 SumatraPDF 只有 Windows 版本，没有手机版。手机用户可使用系统自带的 PDF 阅读功能，或寻找其他移动端阅读器。
如何卸载 SumatraPDF？
安装版：通过 Windows 设置 → 应用 → 找到 SumatraPDF → 卸载。便携版：直接删除程序文件夹即可，不会留下任何残留文件或注册表项。
