功能介绍

了解 WizTree 的核心功能与使用技巧

核心功能

⚡ 极速 MFT 扫描

WizTree 直接从 NTFS 格式的驱动器读取主文件表（MFT），类似于 Everything 搜索引擎的工作方式。绕过文件系统遍历，直接解析磁盘元数据，秒级完成全盘分析。1TB 硬盘扫描仅需约 46 秒，比传统工具快 10 倍以上。还可快速扫描非 NTFS 和网络驱动器。

📊 可视化树状图

独创 Treemap 热力图，根据文件大小直观地显示所有文件和文件夹。文件越大色块越大，一眼看出磁盘空间分布。这使您可以一目了然地发现大文件和大量较小文件的集合，快速定位"空间杀手"。

📁 文件视图排序

"文件视图"按大小顺序列出硬盘上的每个单独的文件和文件夹。支持按名称、大小、日期等多维度排序筛选。快速定位占用空间最大的 Top 1000 文件，高效管理磁盘空间。

🔁 重复文件查找

WizTree 根据名称、大小和（可选的）日期自动定位重复文件。如果文件有重复项，可以通过单击文件名旁边的"+"来查看它们。帮助您快速清理冗余文件，释放宝贵磁盘空间。

🔍 文件名搜索

使用文件视图搜索过滤器按名称或类型快速定位文件。支持通配符搜索（例如 *.mp3）和正则表达式。输入即搜索，无需点击搜索按钮，实时匹配结果，秒级定位任意文件位置。

💾 多种文件系统支持

WizTree 可以扫描 Windows 支持的所有硬盘类型（NTFS、FAT、FAT32、网络等）。通过 USB 连接时，还可以扫描智能手机和相机等 MTP/PTP 设备。覆盖几乎所有存储场景。

📤 导出文件和 MFT 数据

可以将全部或选定的文件信息导出到 CSV（逗号分隔值）文件或复制到剪贴板。可以提取 MFT 文件并转储到文件中。导出的数据可导入回 WizTree 查看，非常适合跟踪文件系统变化。

⌨️ 命令行支持

可以通过命令行参数导出 CSV 和 MFT 文件，实现自动化磁盘审计。非常适合企业 IT 管理员批量分析多台电脑的磁盘使用情况，无需人工干预即可生成报告。

🎯 精准的硬链接处理

与同类应用程序不同，WizTree 可以正确处理硬链接文件（不会多次计算它们）。WizTree 报告的总分配空间将实际匹配 Windows 报告的空间，确保分析结果准确可靠。

🔄 实时刷新

文件变化即时反映，无需重新扫描。删除文件后树状图自动更新，保持分析结果与实际磁盘状态一致。让磁盘管理更加高效流畅。

工作原理

MFT 直读技术让 WizTree 比传统工具快 10 倍以上

📖

就像查字典索引

WizTree 直接读取 NTFS 主文件表（MFT）—— 就像直接查字典的索引目录，而不是逐页翻阅。MFT 记录了磁盘上所有文件的元数据，一次读取即可获取全部信息。

⚡

绕过文件系统 API

传统工具需要逐个遍历文件系统 API 获取文件信息，速度慢。WizTree 直接解析 MFT 二进制数据，跳过低速的文件系统 API，实现秒级扫描。

🎯

准确无误

正确处理硬链接文件，不会多次计算。报告的总分配空间与 Windows 资源管理器显示一致，确保分析结果准确可靠。

两种视图模式

🌳

树状图视图（Treemap）

可视化热力图，文件越大色块越大。直观展示磁盘空间分布，一眼定位大文件。支持点击色块进入子文件夹，逐层深入分析。

📋

文件视图（File View）

按大小排序列出所有文件和文件夹。支持搜索过滤、通配符匹配。快速定位 Top 1000 大文件，配合重复文件查找功能高效清理。

使用技巧

1

右键菜单集成

安装后可在资源管理器右键菜单中直接启动 WizTree 分析当前文件夹，无需每次打开程序选择路径。

2

多磁盘同时扫描

支持同时选择多个磁盘分区进行分析，对比不同磁盘的使用情况，全面掌握存储状态。

3

导出 CSV 报告

扫描结果可导出为 CSV 文件，用 Excel 打开进一步分析。适合长期跟踪磁盘使用变化趋势。

4

命令行自动化

使用命令行参数实现批量扫描和导出，配合计划任务实现定期磁盘审计，无需人工干预。

支持的文件系统

💾

NTFS（推荐）

支持 MFT 直读，秒级扫描。Windows 默认文件系统，性能最佳。

📁

FAT / FAT32

传统文件系统，支持常规扫描。适合 U 盘等移动存储设备。

🌐

网络驱动器

支持网络映射驱动器扫描，分析 NAS 和共享文件夹空间。

📱

MTP/PTP 设备

通过 USB 连接的智能手机、相机等设备也可扫描分析。
