功能介绍

了解 QuickLook 的核心功能与使用技巧

核心功能

⚡ 空格键极速预览

QuickLook 的核心功能。在文件资源管理器中选中任意文件，按下空格键即可弹出预览窗口，再次按下空格键或 Esc 关闭。无需双击打开，无需启动对应程序，毫秒级响应。

📦 百种格式支持

开箱即用支持 100+ 种文件格式预览，包括图片、视频、音频、PDF、Office 文档、压缩包、代码文件等。无需安装额外软件，即可预览几乎所有常见文件类型。

🧩 插件扩展系统

内置格式不够用？通过插件系统轻松扩展。社区提供丰富的插件资源，支持 Markdown 渲染、代码高亮、3D 模型预览等高级功能。安装插件后即可预览更多特殊格式。

🎨 Fluent Design 设计

采用现代 Fluent Design 设计语言，支持 Mica、Acrylic、Tabbed 等多种背景效果。界面美观流畅，与 Windows 11 风格完美融合，提供沉浸式预览体验。

🖥️ HiDPI 与触摸支持

完美支持高分辨率屏幕，在 4K 显示器上依然清晰锐利。同时对触摸屏友好，支持手势操作，在平板电脑和触摸屏笔记本上也能流畅使用。

📁 第三方文件管理器集成

不仅支持 Windows 资源管理器，还兼容众多第三方文件管理器（如 Directory Opus、Total Commander、XYplorer 等）。在任何支持的文件管理器中都能使用空格键预览。

💬 对话框预览

在"打开文件"和"保存文件"对话框中也能使用 QuickLook 预览。选择文件后按空格键，即可在对话框中预览文件内容，避免选错文件。

🔄 持续更新维护

项目自开源以来持续维护，定期发布新版本。修复已知问题，跟进 Windows 最新特性，不断增加新功能。社区活跃，问题反馈响应及时。

快捷键操作

熟练使用快捷键，效率提升十倍

快捷键 功能说明
Space 显示 / 隐藏预览窗口（核心操作）
Esc 隐藏预览窗口
Enter 使用默认程序打开 / 执行当前文件
↑ ↓ ← → 预览上一个 / 下一个文件
鼠标滚轮 放大 / 缩小（图片预览）
Ctrl + 鼠标滚轮 放大 / 缩小（PDF 预览）
滚轮（视频/音频） 增大 / 减小音量
