功能介绍

核心功能详解

OBS Studio 主界面分为来源、预览、混音器、场景等面板，提供专业级的视频制作功能

🎥 视频录制（核心功能）

OBS Studio 最常用的功能。支持多种录制模式，实时合成视频、图像、文本等内容，输出高质量视频文件。包括：

• 显示器采集：录制整个屏幕画面，适合制作教程视频和软件演示。
• 游戏捕获：直接捕获游戏画面，支持 DirectX 和 OpenGL 游戏，无延迟。
• 窗口采集：录制指定程序窗口，不影响其他窗口。
• 视频采集设备：录制摄像头、采集卡等视频输入设备。
• 图片/图像：添加图片、Logo、水印等静态图像。
• 文本来源：添加文字内容，支持自定义字体、颜色、样式。
• 媒体源：播放视频文件，支持循环播放。
• 浏览器源：嵌入网页内容，如弹幕、聊天、网页动画等。

支持 MKV、MP4、FLV、MOV 等多种输出格式，建议使用 MKV 防止崩溃丢文件。

📡 实时直播（RTMP 推流）

OBS Studio 支持 RTMP 协议推流到所有主流直播平台：

• 国际平台：Twitch、YouTube Live、Facebook Live、Trovo、Kick 等。
• 国内平台：Bilibili、虎牙、斗鱼、抖音、快手、西瓜视频等。
• 自定义服务器：支持任意 RTMP 服务器推流。

在"设置 → 推流"中填入平台推流地址和流密钥，点击"开始推流"即可直播。支持多码率自适应，根据网络状况自动调整画质。原生支持单路推流，多平台同步需安装 Multiple RTMP 插件或使用 Restream 服务。

🎨 场景管理

无限场景切换，通过快捷键平滑过渡。每个场景可以包含不同的来源组合，适合不同直播内容。

• 场景切换：通过快捷键或点击切换场景，支持淡入淡出、滑动、缩放等转场特效。
• 画中画：在一个画面中同时显示多个来源，如摄像头画面叠加在游戏画面上。
• 实时字幕：自动生成字幕，支持多种语言识别，提升直播可访问性。
• 场景预览：在切换前预览场景效果，避免直播事故。
• 工作室模式：双视图模式，左侧预览下一个场景，右侧显示当前直播画面，专业切换。

⚡ 硬件编码

支持多种硬件编码器，大幅降低 CPU 占用，提升录制与直播性能：

• NVIDIA NVENC：使用 NVIDIA 显卡的硬件编码器，需 GTX 600 系列及以上。支持 H.264、H.265/HEVC、AV1 编码。
• AMD AMF：使用 AMD 显卡的硬件编码器，支持 H.264、H.265/HEVC 编码。
• Intel QuickSync：使用 Intel 核显的硬件编码器，支持 H.264、H.265/HEVC 编码。
• Apple VideoToolbox：macOS 平台硬件编码，支持 Apple Silicon 和 Intel 芯片。
• 软件编码 x264：CPU 软件编码，兼容性最好但占用高。

建议优先使用硬件编码器，在"设置 → 输出 → 编码器"中选择。

🎙️ 音频混音

内置多通道音频混音器，支持独立调节各音频源的音量：

• 多音频源：支持桌面音频、麦克风、音乐播放器等多个音频源同时输入。
• 实时混音：实时调整各音频源音量、静音、独奏等。
• 音频滤镜：支持降噪、增益、压缩、限制器、噪声门等音频滤镜。
• VST 插件：支持加载 VST2 音频插件，实现专业级音频处理。
• 音频监控：支持监听音频输出，避免回声。
• 多音轨录制：可将不同音频源录制到不同音轨，方便后期编辑。

🔌 插件系统

强大的插件系统，可扩展各种功能：

• 虚拟摄像头：将 OBS 画面输出为虚拟摄像头，可在 Zoom、Teams、微信、QQ 等视频会议软件中使用。
• 多路推流：Multiple RTMP 插件支持同时推流到多个平台。
• 场景切换器：自动场景切换插件，根据时间、窗口、进程等条件自动切换场景。
• 聊天互动：显示直播平台聊天弹幕、礼物、关注等互动信息。
• 字幕生成：语音识别自动生成字幕。
• 源码滤镜：各种视频滤镜插件，如美颜、背景移除、色彩调整等。
• 第三方插件：丰富的社区插件生态，满足各种定制需求。

🎬 转场与滤镜

提供专业的转场特效和视频滤镜：

• 转场特效：淡入淡出、滑动、缩放、旋转、颜色过渡等多种转场效果。
• 视频滤镜：色彩校正、锐化、模糊、色度键（绿幕）、图像掩码混合等。
• 音频滤镜：降噪、增益、压缩、噪声门、VST 插件等。
• 自定义着色器：支持自定义 GLSL 着色器，实现各种视觉效果。
• 卷积滤镜：通过卷积矩阵实现各种图像处理效果。

⌨️ 快捷键与热键

全面的快捷键支持，让操作更加高效：

• 场景切换：为每个场景设置快捷键，一键切换。
• 来源控制：显示/隐藏来源、锁定来源等。
• 录制控制：开始/停止录制、暂停录制等。
• 推流控制：开始/停止推流等。
• 音频控制：静音/取消静音各音频源、调整音量等。
• 截图：快速截取当前画面。
• 自定义热键：几乎所有操作都支持自定义快捷键。

📊 录制与输出设置

灵活的录制与输出配置选项：

• 分辨率：基础分辨率与输出分辨率独立设置，支持 4K、1080p、720p 等。
• 帧率：支持 60fps、30fps、24fps 等多种帧率。
• 码率控制：CBR、VBR、CRF 等多种码率控制模式。
• 输出格式：MKV（推荐，防崩溃）、MP4、FLV、MOV 等。
• 多路输出：可同时录制和推流，使用不同设置。
• 回放缓冲：支持回放缓冲，录制过去几秒的画面。
• 自动分段：按时间或大小自动分段录制。

工作原理

基于模块化架构，高效捕获、合成、编码、输出视频内容

🔬 模块化架构

OBS Studio 采用模块化插件架构，所有功能模块（来源、编码器、滤镜、输出）均可扩展。核心引擎负责音视频数据的捕获、合成、编码和输出，各模块通过插件接口与核心交互。

这种架构使得 OBS 能够灵活地添加新功能，开发者可以编写自定义插件实现各种定制需求，而无需修改核心代码。

⚡ 多线程处理

OBS Studio 采用多线程处理架构，充分利用多核 CPU：

• 捕获线程：负责从各来源捕获音视频数据。
• 渲染线程：负责合成画面，应用滤镜和转场。
• 编码线程：负责将音视频数据编码压缩。
• 输出线程：负责将编码后的数据写入文件或推流。

多线程架构确保各环节并行处理，最大化性能。

🌐 跨平台原生

OBS Studio 原生支持 Windows、macOS、Linux 三大平台，各平台均提供原生构建版本：

• Windows 版：使用 DirectX 作为图形 API，支持 Windows 10/11。
• macOS 版：使用 Metal 作为图形 API，支持 Apple Silicon 和 Intel 双架构。
• Linux 版：使用 OpenGL 作为图形 API，支持 Flatpak 和 PPA 安装方式。

各平台共享核心代码，确保功能一致性和最佳性能。

使用技巧

让 OBS Studio 发挥最大效能的实用技巧

💡 使用 MKV 格式录制

建议使用 MKV 格式录制，即使程序崩溃或断电，已录制的内容也不会丢失。录制完成后可在"设置 → 输出 → 录制"中将 MKV 转换为 MP4。

💡 优先使用硬件编码器

如果您的显卡支持 NVENC、AMF 或 QuickSync，建议优先使用硬件编码器，可大幅降低 CPU 占用，让系统有更多资源处理其他任务。

💡 运行自动配置向导

首次使用时运行自动配置向导，根据您的硬件和网络状况自动优化设置。也可以在"工具 → 自动配置向导"中重新运行。

💡 使用场景预设

为不同用途创建不同场景，如"开始画面"、"游戏画面"、"聊天画面"、"结束画面"等，通过快捷键快速切换，让直播更加专业。

💡 添加降噪滤镜

在麦克风音频源上添加"降噪"滤镜，可有效去除背景噪音。再添加"噪声门"滤镜，可在不说话时自动静音，避免呼吸声等杂音。

💡 以管理员身份运行

Windows 下如果游戏捕获黑屏，尝试以管理员身份运行 OBS。笔记本用户需在 NVIDIA 控制面板中将 OBS 设为"高性能"显卡运行。
