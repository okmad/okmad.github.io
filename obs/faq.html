安装与下载

OBS Studio 是否完全免费？
是的，OBS Studio 是完全免费的开源软件，遵循 GPL 协议。您可以免费下载、使用和分发，无任何隐藏费用或限制。软件不包含任何广告、捆绑软件或恶意代码。OBS Project 不提供任何付费版本，所有名称含"OBS"的第三方收费软件均非官方出品。
OBS Studio 支持哪些操作系统？
OBS Studio 原生支持三大平台：

• Windows：Windows 10 / 11（64 位），Windows 10 1809 或更新版本。
• macOS：macOS 12 Monterey 或更高，支持 Apple Silicon 和 Intel 双架构。
• Linux：Ubuntu 22.04+、Fedora 38+ 等，支持 OpenGL 3.3+，提供 Flatpak 和 PPA 安装方式。
如何确认下载的是正版 OBS？
请仅通过以下官方渠道获取 OBS Studio：

1. 官方网站 obsproject.com
2. GitHub 官方仓库 github.com/obsproject/obs-studio
3. 本中文网站提供的下载链接（均指向官方 CDN）

避免从第三方下载站获取，以免下载到捆绑广告软件或恶意程序的版本。所有官方发布版本均经过数字签名。
安装后界面是英文怎么办？
OBS Studio 支持多语言，包括简体中文。设置方法：

1. 打开 OBS Studio。
2. 进入"Settings → General → Language"。
3. 选择"简体中文"。
4. 点击"确定"，重启 OBS Studio 即可显示中文界面。
安装版和便携版有什么区别？
安装版（Installer）：通过安装程序安装到系统中，会在开始菜单和桌面创建快捷方式，设置保存在用户目录。

便携版（ZIP）：解压即用，无需安装。创建 obs_portable_mode.txt 文件后，所有设置、配置文件、场景、日志等都会保存在程序所在文件夹，适合 U 盘携带或在无权限安装的环境使用。
如何获取旧版本 OBS？
如果您需要适用于旧版本 Windows 或 32 位 Windows 的 OBS Studio，可以访问 GitHub Releases 页面下载历史版本。例如 OBS Studio 27.2.4 是支持旧版本 Windows 的最后版本。访问 https://github.com/obsproject/obs-studio/releases 查看所有版本。

录屏与直播

obs录屏 文件保存在哪？
默认保存在"视频"文件夹中。您可以在"设置 → 输出 → 录制 → 录制路径"中修改保存位置。建议选择空间充足的硬盘分区，并使用有意义的文件名命名规则，方便管理。
obs录屏 黑屏怎么解决？
录屏黑屏是常见问题，解决方法：

Windows 用户：
1. 以管理员身份运行 OBS（右键 → 以管理员身份运行）。
2. 笔记本用户需在 NVIDIA 控制面板中将 OBS 设为"高性能"显卡运行。
3. 游戏捕获模式下，确保游戏类型选择正确（自动或指定游戏）。
4. 尝试使用"显示器采集"代替"游戏捕获"。

macOS 用户：
1. 在"系统设置 → 隐私与安全性 → 屏幕录制"中授予 OBS 权限。
2. 重启 OBS Studio。
如何开始直播推流？
开始直播推流的步骤：

1. 在直播平台（如 Bilibili、虎牙、斗鱼、Twitch、YouTube）获取推流地址和流密钥。
2. 在 OBS 中进入"设置 → 推流"。
3. 服务选择对应平台，或选择"自定义"填入推流地址。
4. 填入流密钥。
5. 点击"确定"保存设置。
6. 添加来源（如显示器采集、游戏捕获、摄像头等）。
7. 点击"开始推流"即可直播。
可以同时在多个平台直播吗？
OBS Studio 原生支持单路推流。如需同时推流到多个平台，有两种方案：

方案一：安装 Multiple RTMP 插件
安装 Multiple RTMP Output Plugin 后，可同时推流到多个 RTMP 服务器，无需额外服务。

方案二：使用 Restream 服务
将 OBS 推流到 Restream，由 Restream 分发到多个平台。需要 Restream 账号，免费版有水印。
应该选择哪个编码器？
编码器选择建议：

• NVIDIA NVENC：如果您有 NVIDIA GTX 600 及以上显卡，首选 NVENC，性能最佳，CPU 占用低。
• AMD AMF：如果您有 AMD 显卡，使用 AMF 硬件编码。
• Intel QuickSync：如果您有 Intel 核显，可使用 QuickSync。
• x264（软件编码）：兼容性最好，但 CPU 占用高，适合没有独立显卡或硬件编码器不可用的情况。

在"设置 → 输出 → 编码器"中选择，建议优先使用硬件编码器。
录制什么格式最好？
推荐使用 MKV 格式录制。原因：

1. MKV 容器即使程序崩溃或断电，已录制的内容也不会丢失。
2. MP4 在异常关闭时可能导致整个文件损坏。
3. MKV 支持多种编码格式。

录制完成后，可在"设置 → 输出 → 录制"中将 MKV 转换为 MP4（工具 → MKV 到 MP4 转换），方便在其他软件中编辑。
如何设置虚拟摄像头？
虚拟摄像头使用方法：

1. 启动 OBS Studio。
2. 点击"启动虚拟摄像机"按钮（在主界面控制面板）。
3. 在视频会议软件（Zoom、Teams、微信、QQ 等）中选择"OBS Virtual Camera"作为摄像头。

Linux 用户注意：需先安装 v4l2loopback-dkms 模块：
sudo apt install v4l2loopback-dkms（Debian/Ubuntu）
sudo dnf install kmod-v4l2loopback（Fedora）
如何降低直播延迟？
降低直播延迟的方法：

1. 使用低延迟编码预设：在编码器设置中选择"低延迟"预设。
2. 减少关键帧间隔：将关键帧间隔设置为 2 秒。
3. 降低缓冲：在"设置 → 输出 → 高级"中调整缓冲大小。
4. 使用 TCP 推流：比 UDP 更稳定，延迟略高但更可靠。
5. 选择就近服务器：选择离您最近的直播平台服务器节点。

性能与优化

OBS Studio 卡顿怎么办？
卡顿优化方法：

1. 使用硬件编码器：优先使用 NVENC、AMF 或 QuickSync，降低 CPU 占用。
2. 降低分辨率和帧率：输出分辨率降至 1080p 或 720p，帧率降至 30fps。
3. 降低码率：适当降低码率，减轻编码压力。
4. 关闭不必要的来源：减少同时显示的来源数量。
5. 关闭后台程序：关闭占用 CPU 和内存的程序。
6. 以管理员运行：Windows 下以管理员身份运行 OBS，提升优先级。
录制文件太大怎么办？
减小录制文件大小的方法：

1. 使用 H.265/HEVC 编码：比 H.264 压缩率更高，同画质文件更小。
2. 降低码率：适当降低录制码率，如 1080p 使用 6000kbps。
3. 降低帧率：非游戏内容可使用 30fps 而非 60fps。
4. 使用 CBR 码率控制：固定码率，文件大小可预估。
5. 降低分辨率：1080p 改为 720p，文件大小减半。
如何优化音频质量？
音频优化建议：

1. 添加降噪滤镜：在麦克风源上添加"降噪"滤镜，去除背景噪音。
2. 添加噪声门：设置阈值，不说话时自动静音，避免呼吸声。
3. 添加压缩器：平衡音量，避免忽大忽小。
4. 使用增益：提升麦克风音量，确保声音清晰。
5. 采样率 48kHz：在"设置 → 音频"中设置采样率为 48kHz。
6. 使用好的麦克风：硬件基础很重要，建议使用电容麦克风或动圈麦克风。

OBS Studio 支持哪些直播平台？
OBS Studio 支持 RTMP 协议推流到所有主流直播平台：

国际平台：Twitch、YouTube Live、Facebook Live、Trovo、Kick、DLive 等。

国内平台：Bilibili、虎牙、斗鱼、抖音、快手、西瓜视频、网易 CC 等。

自定义服务器：支持任意 RTMP 服务器推流，包括自建流媒体服务器。还支持 SRT 和 RIST 协议。
如何安装插件？
安装插件的方法：

Windows：将插件文件（.dll 等）放入 OBS 安装目录的 obs-plugins 文件夹，或 obs-plugins/64bit 文件夹。

macOS：将插件放入 ~/Library/Application Support/obs-studio/plugins 文件夹。

Linux：将插件放入 /usr/lib/obs-plugins 或 ~/.config/obs-studio/plugins 文件夹。

部分插件提供安装程序，直接运行安装即可。安装后重启 OBS Studio 生效。
