项目背景

OBS Studio（Open Broadcaster Software）是一款免费、开源、跨平台的视频录制和实时直播软件。它由 OBS Project 开发维护，遵循 GPL 协议开源，代码托管在 GitHub，由全球社区共同维护。

OBS Studio 最初由 Hugh "Jim" Bailey 于 2012 年创建，最初是一个小型的个人项目，旨在为游戏主播提供一个免费、开源的直播软件。随着项目的不断发展，OBS Studio 逐渐成为全球最受欢迎的视频录制与直播软件之一，被数百万内容创作者、教育工作者、游戏主播和企业用户使用。

OBS Studio 为高效捕获、合成、编码、记录和流传输视频内容而设计，支持所有流媒体平台。快捷键可让视图平滑切换，还有画中画和实时字幕等新功能。软件操作简单，对于新手非常友好，同时提供专业级的功能满足高级用户的需求。

您可以这样理解 OBS Studio

• 一个免费、开源、跨平台的视频录制和直播软件。

• 一个集视频捕获、合成、编码、输出于一体的专业工具。

• 一个支持所有主流直播平台的 RTMP 推流软件。

• 一个拥有丰富插件生态的可扩展平台。

我们的使命

OBS Project 的使命是为每一位内容创作者提供免费、开源、专业级的视频录制与直播工具。我们相信，优秀的创作工具应该是免费、开源、无广告的，让每个人都能自由地表达自己。

OBS Studio 遵循 GPL 协议开源，代码公开透明，无任何隐藏费用或广告插件。项目由全球社区和赞助商共同维护，持续更新迭代，不断优化性能并添加新功能。
