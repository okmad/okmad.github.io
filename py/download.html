💡 安装提示

  • tar.gz 版本解压后运行 bin 目录下的启动脚本即可使用：./pycharm.sh
  • 大多数Linux发行版可通过包管理器直接安装Python：sudo apt install python3 或 sudo dnf install python3
  • 建议使用虚拟环境隔离项目依赖，避免污染系统Python
  • 源码包需自行编译，编译命令：./configure && make && sudo make install
