常见问题解答

关于 Snipaste 使用、授权、功能等方面的常见问题

Snipaste 是免费的吗？

Snipaste 对个人非商业使用完全免费，包含截图、贴图、取色、标注、多屏、HiDPI 等全部核心功能。授权说明：

• Snipaste 1.x 版本：个人与商业使用均永久免费。

• Snipaste 2.0 及以上版本：个人非商业使用免费；商业环境使用需购买 PRO 授权。

• PRO 授权：单设备 $8.99，三设备 $19.99，微软商店 10 设备 $19.99，一次性买断。

注意：绝大多数个人用户使用免费版即可满足需求，PRO 版本主要增加 OCR、条形码解码等高级功能。

Snipaste 怎么用？截图和贴图的快捷键是什么？

Snipaste 使用非常简单，核心操作只需两个快捷键：

1. F1 截图：按下 F1 进入截图模式，鼠标移动会自动识别 UI 元素，或拖拽框选区域。选区后可双击保存、按 Ctrl+C 复制、或按 F3 贴图。

2. F3 贴图：将剪贴板中的图片作为浮动窗口钉在屏幕上。贴图窗口始终置顶，可一边对照一边操作其他窗口。

其他常用快捷键：

• Alt：取色（截图模式或贴图窗口中）

• 空格：进入标注模式（贴图窗口中）

• Ctrl+C / Ctrl+S：复制 / 保存截图

• Esc：退出当前操作

Snipaste 贴图窗口有哪些操作？

Snipaste 贴图窗口支持丰富的操作，让它不只是显示图片：

• 鼠标滚轮 或 +/-：缩放贴图

• 1 / 2 键：旋转贴图（GIF 则跳转帧）

• 3 / 4 键：水平 / 垂直翻转

• Ctrl + 鼠标滚轮 或 Ctrl + +/-：调节透明度

• 鼠标点击穿透：让点击穿透贴图到达下方窗口

• 空格：进入图片标注编辑模式

• Shift + 双击：进入缩略图模式

• 双击：隐藏贴图窗口

• Alt：取色

• 拖拽：移动贴图位置

GIF 动图贴图还支持逐帧播放与速度调节。

如何使用 Snipaste 取色器？

Snipaste 内置像素级取色器，使用方法：

1. 进入截图模式（按 F1），或在任意贴图窗口中。

2. 按住 Alt 键，鼠标移动即可拾取光标位置的颜色。

3. 按 C 键复制颜色值到剪贴板（默认 RGB 格式）。

4. 按 F3 可将颜色贴图为色卡窗口，直观显示。

取色结果支持 RGB、HEX、HSV 等多种颜色格式，可在首选项中设置默认格式。PRO 版本还可在取色器中同时显示多种颜色值。

Snipaste 和其他截图软件（如 QQ截图、ShareX）有什么区别？

Snipaste 与传统截图软件最大的区别在于贴图功能：

• 贴图对照：可将截图钉在桌面作为浮动窗口，对照参考无需切换窗口。这是 QQ截图、微信截图等不具备的核心能力。

• UI 元素自动识别：智能识别窗口控件，一键精准选中，比手动框选更高效。

• 像素级控制：放大镜辅助定位，键盘微调，精确到像素。

• 专业取色器：内置取色器，多格式输出，设计师友好。

• 多屏与 HiDPI：完美支持多显示器与高分屏。

• 轻量免安装：体积小巧，免安装便携版，低占用。

与 ShareX 相比，Snipaste 更专注于"截图+贴图"核心体验，体积更小、操作更简洁；ShareX 功能更全（录屏、上传、OCR 等），但相对更重。

Snipaste 支持哪些平台？支持手机吗？

Snipaste 支持桌面端三大平台：

• Windows：7/8/10/11，提供 64 位、32 位、ARM64 便携免安装版。也可通过微软商店安装。

• macOS：10.13 High Sierra 及以上，提供 Universal 通用版（Apple Silicon M1/M2/M3/M4 与 Intel 双架构）。

• Linux：提供 AppImage 格式，适配 Ubuntu、Fedora、Debian 等主流发行版，支持 Wayland 与 X11。

Snipaste 暂不支持手机端（iOS/Android），目前仅限桌面平台使用。

Snipaste 支持哪些图片格式？

Snipaste 的图片格式支持：

截图保存格式：

• PNG（默认，无损）

• JPG / JPEG（有损压缩）

• BMP（无压缩）

• TIFF

• WebP（2.8.6 版本起支持）

贴图窗口支持的格式：

• PNG、JPG、BMP、TGA、ICO、TIFF

• GIF 动图（支持逐帧播放、速度调节）

此外，剪贴板中的纯文本、HTML 文本、颜色信息也可自动转换为浮动图片窗口。

如何设置 Snipaste 开机自启？

设置 Snipaste 开机自启动的步骤：

1. 右键点击系统托盘中的 Snipaste 图标。

2. 选择"首选项"（或双击托盘图标）。

3. 在"通用"选项卡中，找到"开机自启动"选项。

4. 勾选启用即可。

Snipaste 开机自启后驻留系统托盘，内存占用极低，不会拖慢系统启动速度。建议开启以保证 F1 截图、F3 贴图随时可用。

Snipaste 如何自定义快捷键？

自定义快捷键的方法：

1. 右键托盘图标 → "首选项" → "控制"选项卡。

2. 在"全局快捷键"区域，可修改截图、贴图等全局快捷键。

3. 点击需要修改的快捷键输入框，按下新的快捷键组合即可。

4. 点击"应用"保存设置。

注意：快捷键不能与系统或其他软件冲突。PRO 版本还支持自定义应用内快捷键，灵活性更高。

Snipaste 截图时如何精确控制选区？

Snipaste 提供多种精确控制选区的方式：

• UI 元素自动识别：鼠标移动到窗口控件上会自动高亮选中，无需手动框选。

• 放大镜：截图时自动显示放大镜，像素级查看光标周围区域。

• 键盘微调：使用 W/A/S/D 键可像素级移动光标位置。

• 方向键调整选区：选区确定后，方向键可移动选区位置，Shift + 方向键以 1px 步进调整选区边缘。

• 历史回放：使用逗号（,）和句号（.）键回放截图操作过程。

• Ctrl+A：多次按下可在活动屏幕与全部屏幕间切换选区。

Snipaste PRO 版本有哪些高级功能？

Snipaste PRO 版本（2.0+ 商业使用需购买）额外提供以下高级功能：

• OCR 文字识别：从截图中提取文字，支持腾讯 OCR 与 OCR.space API。

• 条形码/二维码解码：从截图中识别条形码与二维码内容。

• 自定义应用内快捷键：灵活配置各种操作的快捷键。

• 圆角截图：截图时支持较大圆角半径。

• 虚拟桌面支持：贴图窗口在 Windows 11 虚拟桌面间灵活显示。

• 编号标注分组：按组管理编号标注。

• 放大镜标注：在标注中添加放大镜效果。

• 更多高级配置与命令行选项。

个人非商业使用免费版已包含截图、贴图、取色、标注等全部核心功能，大多数用户无需购买 PRO。
