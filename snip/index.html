什么是 Snipaste？

Snipaste 是一款由独立开发者 liulex 打造的截图贴图工具，名字由 Snip（截图）与 Paste（贴图）组合而来。它以"截图 + 贴图"的创新工作流为核心，帮助用户高效完成信息对照与捕捉。

🔵 截图即贴，高效对照

Snipaste 独创的贴图工作流：按 F1 截图，框选区域后再按 F3，截图就会作为浮动窗口钉在屏幕上。你可以一边对照贴图一边操作其他窗口，无需频繁切换，对照参考、代码比对、设计稿对比效率倍增。

🔵 像素级精确控制

截图时自动识别窗口 UI 元素，一键精准选中控件。配合放大镜可进行像素级别的微调定位，支持历史回放查看截图操作过程。无论是截取网页、软件界面还是局部细节，都能精确到像素。

🔵 贴图窗口无限可能

贴图窗口不只是显示图片：鼠标滚轮缩放、1/2 键旋转、3/4 键翻转、Ctrl+滚轮调节透明度、鼠标点击穿透、空格进入标注、Shift+双击缩略图、双击隐藏。GIF 贴图还能逐帧播放，功能强大超出想象。

内置像素级取色器，按 Alt 即可拾取屏幕任意位置颜色，支持 RGB、HEX、HSV 等多种格式并自动复制到剪贴板。丰富的标注工具涵盖矩形、椭圆、箭头、画笔、马克笔、文字、马赛克、高斯模糊等，满足专业标注需求。

Snipaste 是免费的吗？需要付费吗？

Snipaste 对个人非商业使用完全免费，包含截图、贴图、取色、标注、多屏、HiDPI 等全部核心功能。Snipaste 1.x 版本商业使用也免费；从 Snipaste 2.0 开始，商业使用需购买 PRO 授权，个人使用依然免费。PRO 版本额外提供 OCR 文字识别、条形码/二维码解码、自定义快捷键等高级功能。

Snipaste 怎么用？截图和贴图的快捷键是什么？

Snipaste 和其他截图软件有什么区别？

Snipaste 与传统截图软件最大的区别在于贴图功能：可将截图钉在桌面作为浮动窗口，支持缩放、旋转、透明、点击穿透，对照参考无需切换窗口。此外还具备 UI 元素自动识别、像素级控制、专业取色器、GIF 贴图、多屏与 HiDPI 支持等特性，体积小巧、免安装、低占用，是程序员和设计师的效率利器。

Snipaste 贴图窗口有哪些操作？

Snipaste 贴图窗口支持丰富的操作：鼠标滚轮或 +/- 缩放、1/2 键 旋转、3/4 键 翻转、Ctrl+滚轮 调节透明度、鼠标点击穿透、空格键 进入标注编辑、Shift+双击 进入缩略图模式、双击 隐藏。GIF 贴图还支持逐帧播放与速度调节。
