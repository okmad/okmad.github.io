截图功能

智能精准的截图能力，从区域选择到细节控制都恰到好处

🎯 UI 元素自动识别

截图时鼠标移动会自动识别窗口控件与界面元素，一键精准选中按钮、输入框、菜单、图片等区域，无需手动拖拽框选。智能算法支持 Qt、Electron 等多种框架应用，大幅提升截图效率。

🔍 像素级精确控制

内置放大镜辅助定位，可像素级别精确调整截图边缘。配合键盘 W/A/S/D 微调光标位置，实现极致精准的区域选择。支持 Shift+方向键以 1px 步进调整选区，满足像素级截图需求。

⏱️ 历史回放

截图过程中支持历史回放功能，使用逗号（,）和句号（.）键可回放查看截图操作的每一步。方便复盘截图过程，确认选区是否准确，特别适合需要精确截图的专业场景。

🖥️ 多屏与 HiDPI 支持

完美支持多显示器环境，可在任意屏幕上截图与贴图，跨屏操作流畅自然。完美适配 HiDPI（Retina）高分屏，高分屏下截图清晰锐利，混搭 DPI 多屏环境也无偏差。

📏 多种截图模式

支持区域截图、窗口截图、全屏截图、多屏截图等多种模式。可通过命令行参数指定截图尺寸、活动屏幕等，支持预设截图区域与命名规则，满足自动化截图需求。

💾 多格式保存

截图支持保存为 PNG、JPG、BMP、TIFF 等多种图片格式，2.8.6 版本起还支持 WebP 格式。可自定义保存路径、文件命名规则，支持快速保存与复制到剪贴板。

贴图功能

Snipaste 独创的核心特色，将截图钉在屏幕上随时对照

📌

浮动窗口贴图

按 F3 即可将截图作为浮动窗口钉在屏幕最前。贴图窗口始终置顶，对照参考无需切换窗口，代码对照、设计稿比对、资料摘抄效率倍增。

🔍

缩放与缩略图

贴图窗口支持鼠标滚轮或 +/- 缩放，可任意放大查看细节。Shift+双击进入缩略图模式快速缩小预览，双击隐藏贴图窗口，操作便捷流畅。

🔄

旋转与翻转

使用 1/2 键可旋转贴图窗口，3/4 键可水平/垂直翻转。方便从不同角度查看截图内容，满足特殊对照需求。

🌫️

透明度调节

Ctrl+鼠标滚轮可调节贴图窗口透明度，实现半透明叠加比对。将设计稿半透明叠加在实现效果上，精准对比差异，设计师的得力助手。

🖱️

鼠标点击穿透

贴图窗口支持鼠标点击穿透，让点击操作穿透贴图到达下方窗口。既能显示参考内容，又不影响下方窗口操作，工作流丝滑顺畅。

🎬

GIF 动图支持

贴图窗口支持 GIF 动图，可逐帧播放、调整播放速度。1/2 键跳转帧，滚轮调节速度，动图贴图也能精细控制，完美呈现动态内容。

取色与标注

专业级取色器与丰富的标注工具，满足设计与标注需求

🎨 像素级取色器

在截图模式或贴图窗口中按 Alt 即可拾取屏幕任意位置的颜色。取色结果自动复制到剪贴板，支持 RGB、HEX、HSV 等多种颜色格式。取色后可按 F3 将颜色贴图为色卡窗口，方便对照使用。

✏️ 丰富的标注工具

贴图窗口按空格进入标注模式，提供矩形、椭圆、线条、箭头、画笔、马克笔、文字等多种标注工具。每种工具都支持自定义颜色、粗细、样式，满足专业标注需求。

🧩 高级标注工具

除基础标注外，还提供马赛克、高斯模糊、橡皮擦等高级标注工具。可对敏感信息进行模糊处理，橡皮擦可擦除标注内容，撤销重做操作自如。

🔢 编号标注

支持在标注中添加自动编号，方便按顺序标注多个要点。适合制作操作步骤图、标注说明图，让截图说明更加清晰有序（PRO 功能）。

📝 文字标注

文字标注工具支持自定义字体、大小、颜色、背景。可在截图任意位置添加说明文字，配合其他标注工具制作专业的图文说明。

↩️ 撤销重做

标注过程支持完整的撤销（Ctrl+Z）与重做（Ctrl+Y）操作，可随时回退或恢复标注步骤。配合 Tab 键可在矩形/椭圆、线条/箭头间快速切换工具。

剪贴板与转换

智能转换剪贴板内容，让贴图功能更加强大

📋

图片贴图

剪贴板中的图片可直接按 F3 贴图为浮动窗口。支持从浏览器、图片编辑器、其他截图工具复制的图片，无缝衔接工作流。

📄

文本转图片

剪贴板中的纯文本或 HTML 文本可自动转换为浮动图片窗口。复制一段文字即可贴图为便签，方便对照参考。

🎨

颜色信息转图片

剪贴板中的颜色信息文本（如 #06B6D4）可自动转换为颜色色卡窗口。复制颜色代码即可贴图为色块，直观查看颜色效果。

🖼️

多格式图片文件

支持粘贴 PNG、JPG、BMP、TGA、ICO、TIFF 以及 GIF 动图文件。拖拽图片文件到贴图窗口也能直接显示，灵活便捷。

🗂️

贴图分组

支持将多张贴图分组管理，可批量显示/隐藏一组贴图。方便按项目或场景组织贴图，工作区整洁有序（PRO 功能）。

💾

自动备份恢复

贴图窗口支持自动备份与恢复，软件异常退出后重启可恢复之前的贴图布局。重要对照内容不会因意外而丢失，工作连续性有保障。

自定义与配置

高度可定制，打造专属的截图贴图工作流

⌨️ 全局快捷键

所有核心操作均支持全局快捷键：F1 截图、F3 贴图、Alt 取色等。可在首选项中自定义快捷键组合，满足个人习惯与工作流需求。PRO 版本还支持自定义应用内快捷键。

🎨 主题与外观

支持自定义主题颜色、界面字体、托盘图标等外观元素。可跟随系统主题色，深色浅色自由切换，打造专属视觉体验。

⚙️ 详细的配置选项

首选项提供丰富的功能配置选项：截图行为、输出设置、贴图窗口、标注默认值、快捷键等。几乎每一个细节都可调整，满足个性化需求。

💻 命令行支持

提供完整的命令行参数，支持自动化截图：指定截图区域、尺寸、输出路径、活动屏幕等。可集成到脚本与工作流中，实现自动化截图任务。

🚀 开机自启

支持设置开机自启动，开机后 Snipaste 自动驻留系统托盘，随时待命。低内存占用，不会拖慢系统启动速度。

🌐 多语言支持

Snipaste 支持包括中文在内的多种界面语言，社区贡献的翻译覆盖全球主要语言。界面语言可随时切换，无障碍使用。
